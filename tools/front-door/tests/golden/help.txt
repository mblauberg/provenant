Provenant: run work, inspect progress and land changes.

  run       Start work from a template or graph document
            provenant run 'Meet the acceptance criteria' --use task
  status    Show graph, node and attempt status
            provenant status
  output    Read graph, node or attempt output
            provenant output ID
  steer     Queue a steering message for a lane when its provider supports control
            provenant steer ID --file message.md
  stop      Stop a graph, node or attempt subtree
            provenant stop ID
  retry     Retry a graph, node or attempt
            provenant retry ID
  edit      Apply a patch to unstarted graph nodes
            provenant edit ID --file patch.json
  templates  List or show templates from all layers
            provenant templates
  land      Merge on green CI and prune the merged worktree
            provenant land 1947 --wait
  quota     Show and refresh provider quota
            provenant quota
  --full    Complete human detail; --json keeps machine output
  help --all  All commands and advanced options
              provenant help --all
