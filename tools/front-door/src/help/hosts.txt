usage: provenant hosts list|doctor [--json] [host…]

Delegates to scripts/fabric-hosts.
  hosts list [--json] [host…]    configured local host and SSH peers
  hosts doctor [--json] [host…]  local and peer diagnostics; offline peers get
                                typed rows without failing the command

Hosts use per-user <instance-root>/.agent-fabric/hosts.json (default ~/.agents).
With no peers configured, host checks stay local. Every supported MCP chair
can use fabric_hosts with action=list|doctor and optional hosts selectors.
