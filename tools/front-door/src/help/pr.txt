usage: provenant pr checks <number|branch> [--wait] [--timeout S] [--json]

Delegates to scripts/provenant-pr ...
`pr checks --wait` blocks until the PR's required checks for its current head
finish, following a head that moves and waiting for checks not yet registered.
Required contexts come from rulesets or branch protection and match check
names exactly; all must register. If none are required, or they cannot be
read, the finished set must also hold for two polls. Polls gh with backoff
from 30s to 120s. Exit 0 required checks green, 1 any failure, 2 bad
reference, 4 required set unreadable (seen checks passed; success not
claimed), 124 timeout (default 1800s). Without --wait it reports once and
exits 3 if checks are pending. Run it as a background command.
