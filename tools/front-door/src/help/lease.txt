usage: provenant lease <acquire|release|verify|status|push> ...

Delegates `lease <verb>` to runtime/fabric/bin/fabric landing-<verb>, the
one landing lease per project shared with fabric_landing_lease:
  acquire <session> (--expected-sha SHA | --branch B [--remote R]) [--seconds N]
  verify <session> <generation> [--expected-sha SHA] [--branch B [--remote R]]
  release <session> <generation>
  status
  push <session> <generation> <branch> [--remote R]
Each takes --label L and --json; pass acquire's label to later calls.
Exit 0 ok, 1 refused or stale, 2 usage, 3 held by another holder or a push
in progress. `provenant fabric landing-acquire --help` shows the flags.
