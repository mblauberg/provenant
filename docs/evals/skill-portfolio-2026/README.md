# Skill portfolio evaluation

The [routing holdout](routing-holdout.yaml) is an unexecuted input for a
future evaluation, not evidence of current routing quality. Freeze a protocol
and record actual routes and terminal outcomes before drawing conclusions.

The [predecessor dataset and results](predecessor/) cover an earlier catalogue;
`summary.json` retains its historical evidence. These synthetic cases do not
measure production task success. Current acceptance is owned by
the [global rules](../../../GLOBAL-AGENTS.md).
