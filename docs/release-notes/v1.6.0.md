# Provenant v1.6.0

Released 5 November 2026.

This release improves lane isolation, quota-aware routing and review guidance, and fixes installation and provider issues. See Breaking changes for configuration and preset explanation updates that need action.

## Breaking changes

- **Retired review knobs and the `rigorous` profile are no longer accepted.** Remove them from `config.toml` and select `balanced` or `economy` (#2746).
- **Duplicate `[knobs] domains.routing.*` entries are no longer accepted.** Move routing settings under `[domains.routing]` or remove them with `provenant config migrate` (#2746).
- **The test-only `confinement.census_host_list_complete` knob is retired.** Run `provenant config migrate` to remove it; native acceptance uses `PROVENANT_CENSUS_HOST_LIST_COMPLETE` (#2746).
- **Preset explanations use `admission`, `inspection` and `pending`.** Update consumers of `execution` or `validation_error`. Explanations and submission now use the same static admission checks (#2821).

## Behaviour changes

- Route selection and admission exclude uncalibrated partial quota headroom by default. Set `routing.allow_unknown_partial_headroom` to accept it; an observed exhausted lower bound still blocks the route (#2819).
- Route selection and launch preparation check requested write and network controls against adapter capabilities (#2819).
- Automatic route fallback applies only to confirmed local preparation refusals; launched tasks keep their route. A quota-stopped writer can continue from its recorded handoff on the same model after custody release, and configured read-only result-quality escalation also waits for custody release (#2819).
- Installed agent instructions let the chair decide which branches and worktrees to remove, including abandoned or superseded work, subject to the recorded-tip and live-writer safeguards. Agents may rebase, rewrite and force-push with lease their own unmerged branches; shared branch rewrites and pushes still require user authority.
- Installed review guidance makes planner-led review councils the default, with risk floors and a bounded repair loop.
- Installed skills guide agents to use stacked pull requests for dependent changes (#2849).

## Additions

- Lanes stage user skills in a read-only tree, copying linked content unless it resolves into a credential root. Skipped content appears in the attempt receipt; sandbox profile-size and grant-count defaults also increase when a lane needs more capacity (#2818).
- Projects can give writer lanes access to existing shared test-lock paths and provide read-only toolchain roots. Lanes can locate the primary checkout through `PROVENANT_PRIMARY_CHECKOUT` (#2829, #2818).

## Fixes

### CLI and install

- Lane watches and since filters accept duration suffixes such as `30m` and `1d` (#2738).
- The CLI reference reports each command's numeric bounds and required flags from its grammar, including the distinct limits for configuration and quota history (#2751).
- Source installation works again (#2815).
- Run refusals carry bounded diagnostic details and next actions, while remote and MCP errors omit unanchored host paths and untrusted source text (#2820).

### Lanes and settlement

- Claude and agy lanes launch when optional skill or toolchain grants fall inside a credential root; omitted grants appear in the attempt record. Required grants inside a credential root still refuse with a diagnostic (#2810).

### Git and safety

- The pre-push hook allows non-fast-forward updates to topic branches, so writers can push rebased branches (#2852).

### Accounts, quota and routing

- OpenCode read-only profiles can run system grep (#2471).
- OpenCode stops stalled processes after a quota refusal and cools down free routes so pools can select other members (#2475).
- Compact output, the menu bar and the console show partial quota usage as a lower bound; the console rounds percentages down, and pacing avoids uncalibrated partial windows (#2476).
- OpenCode read-only search can load ripgrep's required libraries, including Homebrew installations, while keeping lane state and credential stores inaccessible (#2806).

### Pipelines and graphs

- Preset inspection shows parameter details in compact output (#2514).
- Default graph limits allow the bundled `big-batch` preset to expand, and pressure collection uses the configured retention periods (#2747).
- Review councils can settle when synthesis cites upstream findings by id (#2848).

### Fabric and MCP

- A retired graph limit setting now produces an unknown-key warning (#2746).
- Composites retain a bounded, severity-ranked findings export when their members exceed the checkpoint cap, so review councils can continue (#2813).

### Telemetry and providers

- Provider sign-in failures are classified as `auth_required`, preserving read-only route fallback and prelaunch authentication refusals (#2744).
