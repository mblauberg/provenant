# Provenant v1.6.1

Released 5 November 2026.

This release cuts supervisor CPU use while lanes run or wait and makes graph launches, writer continuations and account recovery more reliable. See Breaking changes: drain active runs before upgrading.

## Breaking changes

- **Retry decisions now require a typed cause and action.** Drain active runs before upgrading; decisions from the previous format are no longer read.

## Behaviour changes

- `provenant tracker lint` advises on stale issue references and missing
  acceptance or verification without blocking work. Tracker and scope guidance
  checks issue premises and acceptance against the tree, with an optional
  critique for design-heavy issues (#2885).
- Worker census now records typed taints (`TaintCause`), distinguishing lock contention from census uncertainty (unreadable working directories, unplaceable paths, or incomplete listings) so admission policies can retry contention while keeping uncertain roots fail-closed.
- An unreadable or unplaceable process now taints only roots it could occupy given the evidence; affirmative evidence of a different root does not taint unrelated roots, while wholly unplaceable processes fail closed across all candidate roots.
- Live-writer refusals distinguish and name the evidence kind found (`working directory`, `executable image`, or `other held path`) instead of assuming any holding process had its working directory inside the tree (#2760).
- `provenant land` gates ordered batches, including an unflagged single PR by default, on an integration candidate and records outcomes and recovery evidence. Confirmed landings run safe local cleanup; refused cleanup is reported and retried without blocking later landings. Recovery rechecks PR heads, approvals and bases before retrying an uncertain publication, and uses a configurable settle interval when it cannot safely retry. Use `--shadow` to compare its decisions before switching from another lander (#2856).
- Standard reviews now include simplicity and reliability lenses, broadening default coverage (#2871).
- Graph nodes seal the effective settlement retry allowance and its origin. Preset and node `retry.retries` overrides take precedence; verified pre-launch preparation fallbacks do not consume it (#2697).

## Additions

- An experimental test-tier selector chooses touched crates and mapped integration targets; remote runners support full and stress tiers, with CI quarantine exclusions and an optional test-thread cap (#2887).
- Added `--admission-timeout` to `provenant run` and `provenant dispatch` with configurable default in `[domains.run] admission_seconds`, visible origin reporting in `--explain`, and transient worktree registry lock retries within the admission window (#2760).

## Fixes

### Lanes and settlement

- Lane views show when a failed attempt is retrying and identify its retry lineage (#2745).
- Default lane waits summarise oversized settled backlogs while continuing to wait for unsettled lanes (#2768).
- Writer continuation briefs show uncommitted Unicode and renamed paths as Git reports them (#2786).
- Writer continuations refuse preparation when Git cannot inspect predecessor edits, with an explicit diagnostic (#2786).
- Writer continuations report uncommitted predecessor paths even when the predecessor did not create a commit (#2786).
- A writer continuation after predecessor commits now launches pinned to the predecessor head instead of being refused (#2786).
- Uncommitted predecessor edits are preserved during writer continuation and listed in the continuation brief, or named in continuation refusals (#2786).
- Graph execution follows quota-limited writer continuations to terminal success and preserves the node source as the lens review diff base (#2786).
- Writer source mismatch errors now name both commits to help diagnose a refused launch (#2786).
- Lanes stop promptly when a provider reports a structured quota refusal on stderr and keeps running (#2824).
- Agy lanes settle correctly when their final answer is repeated (#2862).
- Lanes include path-bearing permission errors from captured output or decoded answers in their result, helping diagnose access grants (#2876).

### Accounts, quota and routing

- Quota shows known login expiry, warns ahead of time and notifies registered local chairs without sharing credentials. Expired logins and account-specific recovery are visible in quota, doctor and route diagnostics (#2880). OpenCode allows a new launch after a stale sign-in observation, with a warning when its account status cannot be checked separately.

### Pipelines and graphs

- Graph writers stop before a capacity redraw or quota account switch when their worktree and publication state have not been verified. Family-constrained graph routes also stop instead of redrawing after capacity failures (#2697).
- Transient graph launch failures retry within an admission window instead of stopping after three retries (#2760).
- Graph writer initialisation retries a contended worktree registry lock instead of immediately blocking the node (#2760).
- Generator-evaluator runs can reconcile large lens results within the prompt cap and continue when one lens returns malformed findings, provided the lens threshold is met (#2860).
- Composite expansion errors identify invalid or duplicate node IDs and suggest how to correct them. Checkpoint limit errors also suggest splitting the graph into smaller batches (#2861).
- Large inherited disposition metadata is trimmed with a warning while finding identities and locations remain available.
- Big-batch admission reserves deferred review panels and bounds inherited disposition findings in the checkpoint.
- Planner limits count pattern instances as emitted, while expanded graphs remain subject to host limits. Graph status also shows the planner error when its fallback fails (#2863).

### Fabric and MCP

- Findings keep their origin through synthesis, so later nodes can settle the original and its copies together (#2857).

### Supervisors

- Supervisors follow lane process events and use a bounded tree walk between full censuses, reducing process-table work and unnecessary wakeups while lanes run or wait (#2886).
- When writer evidence or the original lock is removed, a supervisor can retire after proving the provider tree and original lease are quiescent, keeping any unresolved fence rather than retrying indefinitely.
