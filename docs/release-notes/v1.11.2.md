# Provenant v1.11.2

Released 14 November 2026.

This patch release stops idle `provenant status --wait` calls from using CPU, and fixes `provenant pr watch` after a push.

## Fixes

- An idle `provenant status --wait` no longer rereads the run store, graph checkpoint and repository every 500 ms. It rereads when those files change, at least every 10 seconds, and once more before its deadline. Waits on attempts held by a peer host, relayed reads and pull requests still read at the configured interval. On a host with many waiters, each one previously held about 14% of a core (#3276).
- `provenant pr watch` no longer reports a failure when the only checks reported right after a push are skipped jobs; it waits for the real workflows, as it does when none are reported (#3259).
