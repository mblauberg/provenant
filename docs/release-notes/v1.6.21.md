# Provenant v1.6.21

Released 8 November 2026.

A writer's result no longer reports an interim message as its answer, budget stops leave a handoff, and cloud placement submits on real hosts: Claude through a pseudo-terminal, and Codex through an optional thread-API client. There are no breaking changes.

## Additions

- Codex cloud placement can use a configurable thread-API client for environments the official CLI cannot list. Select `thread` in the host's `[providers.codex.cloud]` settings (#2889).

## Fixes

- A writer's result no longer reports an interim message, such as "I'll stop early", as its answer when the writer went on to do more tool work. The Claude fallback text applies only when the assistant's text is the last thing before the end of the stream; otherwise the lane settles for review as having sent no final message.
- A writer stopped on its token budget commits its leftover work as `wip: stopped on budget (N files)` with the changed paths listed in the body (up to 20, then "and K more"). When the writer sent no final message, `result.md` now names the commit and paths, says the remaining work is unknown, and carries a `stopped_early` handoff.
- A cloud submission the provider CLI refuses now fails with the CLI's error. An uncertain submission, such as a timeout, stays recoverable and is reported as unknown rather than failed, and `reconcile` settles retained stuck submissions the same way (#2889).
- `claude --cloud` submissions now work on a real host: the owner runs the submit under a pseudo-terminal, which the CLI requires, and reads the session ID from the `Resume with: claude --teleport` line. A refused submission keeps the CLI's first error lines in the saved cloud job, so `status` and `output` show why instead of an empty `submitting` state.
