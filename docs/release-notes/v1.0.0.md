# Provenant v1.0.0

**Date:** Unreleased

Provenant v1.0.0 is the Rust rewrite of the agent harness front door. The
Python and Node tooling it replaces has been removed. Generated from the
`git log` and merged pull requests since the Python front door was deleted
(#1286). Per [ADR 0024](../adr/0024-git-log-and-adrs-own-history.md), this file
is a release artifact and is not maintained between releases.

## Added

- Rust front door with native hooks and registry-driven installation (#1401).
- Fabric coordination in Rust: identity and coordination CLI, MCP transport
  with typed tools, durable peers, and a GUI-session LaunchAgent for peer
  requests that need keychain access (#1389, #1383, #1409, #1486).
- Run execution in Rust: dispatch, admission, controls (cancel, resume,
  reconcile) and telemetry stats (#1410, #1412).
- Provider activation from live confined recordings for Codex, Claude and Agy,
  plus an OpenCode adapter and a Cursor launch path (#1411, #1482, #1322, #1489).
- Live quota sources, utility routing with usage counters, and opt-in
  quota-based account switching for the chair (#1420, #1421, #1436).
- `config set` and `config unset` backed by a live knob registry (#1419).
- Staged installation of verified release assets, with a Cargo example for
  packaging (#1423).

## Changed

- Configuration is a typed single TOML file, with a harness cut-over and
  retired routing configuration (#1369, #1391, #1430).
- Routing resolves explicit models and named routes (#1393).
- Every adapter is enabled by default (#1489).
- Lease-backed worktree writer dispatch, and peer writers create and deliver
  from their own clone (#1429, #1483).
- `worktree remove` deletes merged branches (#1484).
- Destructive git and shell patterns are guarded by hook rules (#1406).
- Read-only lane grants are bounded, and run stores open read-only for readers
  (#1426, #1431).

## Removed

- The Python front door (#1286) and the legacy Python and Node tooling (#1405).
- UI tooling and workflow accelerators retired from the workflow surface
  (#1365).
- Dead selector, projection and private layout tests (#1349).

## Fixed

- Orphaned attempts are settled and proven leftover processes are stopped
  (#1481). macOS descendants that detach are ended before the census (#1475).
- Confinement grants compose into production dispatch, and provider identity
  binds accounts and quota readiness (#1443, #1442).
- Resumed graph launches replay under their recorded launch actor (#1480).
- Robust worktree creation, and clearer writer dispatch refusals (#1479).
- Quota refusals clear correctly, and unfinished worktree Git operations are
  guarded (#1418).
- Fabric MCP single-operation tools publish without `oneOf` (#1491), and the
  Fabric store cold-open race is fixed (#1380).
- Provider streams tolerate duplicate JSON members (#1490).
- Test flakes removed at their causes (#1478).
- Native macOS menu bar for quota (#1494).
- Proc-macro dylibs stay unstripped in release builds (#1339).
