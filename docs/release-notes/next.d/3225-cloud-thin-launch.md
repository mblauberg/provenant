## Breaking changes
### Pipelines and graphs
- Cloud jobs are replaced by one thin launch. `provenant cloud launch --file BRIEF` submits a brief to a Claude or Codex cloud session and prints its link; `provenant cloud collect KEY` puts the pushed branch, or the Codex diff, in a new worktree. Provenant no longer tracks, polls or cancels cloud work. Removed: the `attempt.cloud` and `attempt.placement` graph and `--set` fields (now refused with a pointer to the launch command), the `providers.codex.cloud.transport` and `.command` settings, `domains.lanes.cloud_targets.*` and `projects.*.cloud_target`, the `cloud_*` lane states and the `cloud`, `cloud_state` and `cloud_jobs` status fields, and `scripts/cloud-environment` and `scripts/cloud-verify`. Delete any `[providers.codex.cloud]` table from host configuration; it is now ignored with a warning. Setup is in `docs/runbooks/cloud-launch.md` (#3225).
