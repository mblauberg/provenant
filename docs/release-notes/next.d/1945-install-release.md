## Additions

- `install.sh` installs checksum-verified macOS arm64 release packages, or builds the pinned toolchain with `--from-source`. A first interactive install guides provider, instruction, hook and Claude account setup. Bare installs detect harness CLIs and Claude account directories, and reruns keep the recorded selection.
- `provenant upgrade` upgrades this host and registered Fabric peers together and reports any host that fails.
- Tagged releases publish packages and checksums with the committed release notes.
