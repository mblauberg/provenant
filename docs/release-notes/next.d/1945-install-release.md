## Additions
### CLI and install

- `install.sh` installs checksum-verified macOS arm64 release packages, or builds the pinned toolchain with `--from-source`. A first interactive install guides provider, instruction, hook and Claude account setup, and later runs keep the recorded selection (#1945).
- `provenant upgrade` upgrades this host and its registered Fabric peers together, and reports any host that fails (#1945).
- Tagged releases publish packages and checksums with the committed release notes (#1945).
