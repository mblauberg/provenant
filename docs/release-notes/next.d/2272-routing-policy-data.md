## Behaviour changes
### Accounts, quota and routing
- Load bundled model policy from embedded rule data, including cache ratios, compaction windows and DeepSeek's peak schedule. Existing configuration and account rules override those defaults. Writer cost advice uses configurable exact model classes and pool order from catalogue data instead of model-name substrings. Default policies for catalogued routes are unchanged. Uncatalogued Opus IDs no longer warn until they are added to `tools/front-door/crates/routing/assets/writer-advisory.toml`. A `[domains.routing.writer_advisory]` table overrides only the fields it names, and an omitted `label` keeps the bundled "Opus" class instead of generic writer advice (#2272).
