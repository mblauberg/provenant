## Fixes
### Git and safety
- A sandboxed lane's private Git configuration no longer includes the host's global Git configuration in full, and the lane no longer reads the host system file. It is built from an allowlist of keys in the host system and global files (identity, aliases, colour, core, diff and merge presentation, the Git LFS filter, and `url.*.insteadOf` rewrites that carry no password or token), with no include of and no read grant on the host files. An allowlisted value that carries a credential is withheld, so a token in `http.*.extraHeader`, a rewrite URL, an alias or an inline credential helper cannot reach the lane. Withheld key names, never values, are recorded in the launch receipt, and a withheld required filter driver warns at launch. `domains.lanes.git_config_allow` passes further keys deliberately. Unsandboxed lanes still read the host configuration in full. (#3584)
