## Behaviour changes
### Commands

- `provenant land` reports a merged pull request as one line and exit 0 even when cleanup is outstanding; the sweep finishes the cleanup. (#3124)
- `provenant check release --base` and `--head` accept any unambiguous revision, such as a tag, and resolve it to a commit. (#3124)
- A failed run read now names its cause in the error. `telemetry stats` reports an unreadable plan-value or partial-signal source as an `unavailable` field with its cause instead of failing the report. (#3124)
- Lane preambles print limits as plain numbers. `quota history` returns the newest 50 readings by default. (#3124)
