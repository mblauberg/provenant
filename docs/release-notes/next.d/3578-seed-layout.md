## Fixes
### Lanes and settlement
- Age seeded Cargo dep-info under every build layout. Cargo 1.100 moved fingerprints from `.fingerprint/<unit>/` to `build/<package>/<hash>/fingerprint/`, so the aging pass found nothing and a seeded worktree could again reuse another branch's artifacts (#3561). The pass is now driven by the fingerprints: it finds them in a bounded walk, reads which dep-info each unit checks and ages exactly those files, so units of any kind and any layout are covered. A fingerprint it cannot read, a named dep-info that is missing, or a seed that names none is not published: the lane builds cold and reports `seed_layout_unrecognised`. A test builds with the pinned Cargo, including a member with a build script and a member that depends on another, and checks that all of them rebuild while registry-style dependencies stay fresh. (#3578)
