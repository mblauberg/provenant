## Behaviour changes
### Pipelines and graphs

- The skills are reworked around the presets and a spec gate. The workflow set is now 20 skills in `skills/` plus 8 tool and stack skills in `library/`, and the catalogue stays under 8,000 characters. `orchestrate` leads with `provenant run --preset`, `implement` treats the `deliver` preset as the default loop, and `code-review` owns the review rubric and its lens names. `deliver` narrows to non-software acceptance and the outcome report, and `release`, `retrospect`, `evaluate`, `refactor` and `diagnose` are rewritten around commands that exist. `implement`, `code-review`, `release`, `tracker` and `session` now read repository specifics from the repo's own `AGENTS.md`, `CONTRIBUTING` and runbooks (#2350).
- Four skills are retired and their behaviour moved. `autopilot` is now part of `session` (continue toward a goal, STOP semantics, "idle is not done"). `work-map` is now part of `tracker`, where the parent epic is the map. `grill-me` and `prototype` are now part of `scope` as its interview mode and prototype contract; kept prototypes live in `engineering-docs` and `ui-ux-design`. `scope` ends in a one-screen approval digest, `tracker` defines Epic, Feature, Task and Bug and drops Decision issues, and `setup-repo` ships matching issue forms and sets preset rules and the autonomy level (#2350).
- `tdd` is renamed `test-design`. It now covers which tests to write and how to prune them, and still triggers on "TDD". Update any personal references to `/tdd` (#2350).
- The writing skills are rewritten. `natural-writing` steers by a short mechanism catalogue instead of word lists, `engineering-writing` keeps only the owner overlay, `legal-writing` drops generic prose guidance, and `engineering-docs` separates durable from ephemeral docs and limits ADRs to architecture (#2350).
- New library skills `rust`, `vitest` and `zod` cover the silent semantics and common agent slips of those stacks, with version facts in dated references. `d2-diagrams` moves from `skills/` to `library/`, alongside `playwright`, `react-performance`, `tanstack` and `typescript-clean-code`. Herdr notes move to `docs/runbooks/herdr.md` (#2350).
