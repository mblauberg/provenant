## Additions
### Chair, inbox and console

- The Console inbox is a native three-column window with smart filters, per-project counts, a dense request list and a Markdown detail pane. Rows show the request kind, project, session, relative age and a blocking marker; the detail pane marks the recommended option and keeps delivery and stale-revision results inline.
- The Console is keyboard first: j and k move, 1 to 9 choose an option, Return sends, ⌘F searches, ⌘1 to ⌘5 choose filters and ⌘R refreshes. It also has a real empty state, an error state that keeps the last list, a restored window frame and VoiceOver labels on every control.
