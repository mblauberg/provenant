## Breaking changes
### CLI and install

- **Graph commands use a single graph, node or attempt target.** Use the target syntax shown by `provenant help`; older identifiers and prefixed targets are removed. (#3175, #3177)
- **Use `wait` to wait for work.** Waiting options on other commands have moved to `wait`; waiting does not stop the work. See `provenant help wait`. (#3179)
- **Removed commands and flags need updated usage.** Consult `provenant help` for the current command surface. (#3078)
- **`retry` starts a fresh attempt.** Supply a new brief or extension if the attempt needs different instructions. (#3078)
