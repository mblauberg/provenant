## Breaking changes
### CLI and install

- **Every graph-work verb takes one target, `NAME[/NODE[#N]]`.** `status`, `wait`, `output`, `trace`, `stop`, `retry`, `steer`, `reconcile`, `console detail`, `lane deliver`, `pr open --from-attempt` and `--review`, and `telemetry cost` and `trace` name a graph, one of its nodes, or that node's Nth attempt. Attempt IDs, run and task triples, hex prefixes and the `lane:`, `graph:`, `operation:` and `land:` prefixes are no longer targets. A target reads only its own graph's checkpoint, and an ambiguous one still lists its candidates. (#3175, #3177)
- **`wait` is the one way to wait for work.** `provenant wait [TARGET]... [--pr NUMBER]... [--any] [--follow] [--timeout SPAN]` resolves every target first, then exits 0 on success, 1 on a failed target, 2 on a bad target, 5 when a target needs input and 124 when the budget runs out; the work carries on either way. With no target it waits for the project's running graphs. `--wait` is removed from `status`, `stop`, `retry` and `pr status`, and `status --until` and `--follow` move to `wait`. (#3179)
- **`status` lists graphs and never hides running work.** With no target it prints `NAME STATE TEMPLATE NODES AGE` for every unsettled graph, then graphs settled in the last day, up to 20 rows, and says how many settled graphs it left out. A stopped or failed graph's line names its cause. `--all` lists every graph a page at a time. (#3181)
- **Removed commands and flags print their replacement in one line.** `dispatch`, `lanes`, `resume`, `cancel`, `continue`, `redo`, `preset`, `review`, `stats`, `pr land`, `fabric graph` and `quota usage` are gone, as are `status --target`, `--stats` and `--by`, `output --trace` (use `trace`), `retry --node`, `--prompt-file`, `--prompt-stdin` and `--no-fallback`, `reconcile --id`, `telemetry stats --run-id`, `--by` and `--detail` (use `telemetry cost`), and `--host` on every verb except `run`. Each exits 2 with the command to use instead. (#3078)
- **`retry` starts a fresh attempt.** It no longer continues the provider session of an earlier attempt; pass `--brief` or `--extend` to change what the new attempt does. (#3078)
