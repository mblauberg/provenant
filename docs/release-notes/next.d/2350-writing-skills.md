## Behaviour changes
### CLI and install

- The writing skills are rewritten: `natural-writing` now steers by a short mechanism catalogue instead of word lists, `engineering-writing` keeps only the owner overlay for agent-written docs, `legal-writing` drops generic prose guidance, and `engineering-docs` separates durable from ephemeral docs and limits ADRs to architecture. `d2-diagrams` moves from `skills/` to `library/` (#2350).
