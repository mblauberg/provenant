## Fixes

- New worktree branches are refused when the name differs from an existing local or remote-tracking branch only by case (including non-ASCII case) or by a path prefix (#2132).
- Origin refresh skips advertised branches whose names collide by case and warns. It fails only if the remote default branch collides. It also refuses, naming both spellings, when two advertised names, or an advertised name and an existing tracking ref, differ only by Unicode normalisation. `HEAD` counts as an existing name, so a branch called `head` collides with `origin/HEAD` (#2132).
- Remote worktree bases and git-context bases are pinned to the commit the remote advertises, with revision operators such as `~1` applied to that commit, for every spelling of the tracking root. A base that resolves to a remote-tracking ref the remote did not advertise, such as `Origin/main` on a case-insensitive filesystem, now fails instead of using the local commit. Pre-push uses the advertised default branch (#2132).
