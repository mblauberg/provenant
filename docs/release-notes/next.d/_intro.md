Provenant 2.11.0 settles every lane through one classifier that reads a sealed evidence record, pins each graph's subject at admission so a later push cannot change what a lane reads or reviews, and checks each launch against the adapter's declared capabilities. The lane verb `provenant handoff` is now `provenant declare`, settlement and read-source names in JSON, config and smoke parameters change without aliases, and stored run records, graph checkpoints and the fabric store move to schemas 2.10.0 cannot read, so drain live lanes and upgrade every host together.
