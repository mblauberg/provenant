## Behaviour changes
### Telemetry and providers

- `provenant telemetry stats` now names the project its figures cover and how many queued or running attempts it leaves out, and says how to see other projects. Its `--by` groups with no work context are labelled `unattributed`. Reasoning tokens get their own line when a provider reports them. A host chair cost is no longer shown as complete while some chair sessions could not be read (#2350).
