## Behaviour changes
### Chair, inbox and console

- Global rules now treat a doc, ADR, memory or existing behaviour as evidence of a past decision, and ask agents to name the structural option beside the small one (#3073).
- A spec is now the best current statement of the outcome: implementers raise a flaw with evidence rather than weaken it, and a chair may revise an agent-written criterion through a dated revision that cites the evidence (#3073).
- The risk-tier table no longer has blast-radius or migration rows, and the review-floor ratchet wording is gone (#3081).
