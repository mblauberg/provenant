## Behaviour changes
### Accounts, quota and routing

- The OpenCode Go catalogue drops Kimi K2.7 Code, MiMo V2.5, Muse Spark 1.2 Contributor and Go-hosted Claude Haiku 5.5, and replaces MiniMax M3 with MiniMax M3.1 Flash and Qwen3.7 Plus with Qwen3.8 Flash. Both replacements are below the default $60 allowance floor, so they run only when the floor is lowered. Pools are unchanged: DeepSeek V4.1 Flash and GLM-5.3 Flash remain the routed Go models.
