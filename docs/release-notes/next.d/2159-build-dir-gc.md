## Behaviour changes

- Lanes now build with `CARGO_INCREMENTAL=0` and `CARGO_PROFILE_DEV_DEBUG=line-tables-only`. A lane's target no longer accumulates incremental sessions and carries line tables instead of full debug information. Set `cargo_incremental` and `cargo_debug` in `[domains.fabric.lanes]` to restore either; a value already in the lane environment still wins.
- Fabric collects idle Cargo profile directories in lane caches, least recently used first, until the allocated bytes of all profile directories, idle and busy, are within `domains.fabric.lanes.build_dir_max_bytes` (20 GiB by default) and free space is at least `gc.free_floor`. A directory is idle only when it can take an exclusive `flock` on all of Cargo's `.cargo-lock`, `.cargo-build-lock` and `.cargo-artifact-lock`; a directory with any lock held is never removed. When busy directories alone exceed the cap, the sweep removes every eligible idle directory and stays over. Collection runs when a lane settles, when admission finds free space below the floor, and in `provenant gc`. It measures without a lock, stops when the cap and floor already hold, and holds the host admission lock only while it removes.
- A profile directory written within `domains.fabric.lanes.build_dir_grace_seconds` (15 minutes by default) is never removed, even with its Cargo locks free, because test and run binaries execute after Cargo drops its locks. It protects only recently written directories: a test or run binary that runs longer than the grace without writing under `target/` is unprotected unless a Cargo lock is still held. Set it to 0 to remove the protection.
- `provenant gc` reports the lane build directories removed or reclaimable, the bytes reclaimed, the directories kept as busy or recent and the lane build output that remains.
- A settling lane walks the lane caches at most once per `domains.fabric.lanes.build_dir_survey_interval_seconds` (5 minutes by default), unless free space is below `gc.free_floor` or the last walk found the total within 10% of the cap. While free space stays below the floor, each settlement walks, because reclaiming is the point.
