## Behaviour changes

Housekeeping runs at lane settlement and worktree removal. Active supervisors
pause their own builds below `gc.free_floor` and resume at that same floor.
The daily GC backstop remains. Install quietly retires the old periodic
disk-guard LaunchAgent.

Install and GC default output shows aggregate counts and exceptions. JSON keeps
detailed records, with successful install actions recorded once. Disk-floor
refusals name available space, the floor and `provenant gc --apply`.
