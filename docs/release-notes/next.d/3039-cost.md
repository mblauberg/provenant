## Fixes
### Lanes and settlement

- Fabric settlement immediately queues detached GC to free completed lanes, with durable retries on each host tick. Disk reporting and GC previews use bounded filesystem samples, and previews reuse run-size accounting. GC can cap the total lane Cargo cache with `gc.lane_cargo_cache_max` (32 GiB by default), retaining live writers and unknown ownership (#3039).
