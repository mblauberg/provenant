## Breaking changes
### Work identity and telemetry

- Peer attempt summaries, placements, fetch destinations and console identities carry the canonical work key. Peer placements use format 2; earlier placements are refused. Fetch destinations include host, project, graph, node and attempt.
- Chair associations are per project and graph. Fabric schema 16 replaces the run-keyed chair table; drain or reset earlier Fabric state as part of the cut-over.
- `telemetry backfill` is removed. Settlement writes graph/node identity to the existing usage-ledger row shape. Kept 1.x rows remain readable, including historical backfill rows whose run and task identifiers are opaque labels.

Refs #3078, #3175.
