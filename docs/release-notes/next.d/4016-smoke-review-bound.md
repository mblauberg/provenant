## Fixes

### Lanes and settlement

- `run smoke` and `upgrade --verify` no longer review the caller checkout's last commit. Both run one hermetic lifecycle: a deterministic nonce fixture repository is built under `domains.smoke.fixture_root` (default `.local/state/provenant-smoke`, home-relative) in the home of every target host, locally and on peers through the `SmokeFixture` peer protocol (protocol 16). The graph's `review-write` node reviews the writer's own commit against `diff_base`, which defaults to the fixture head and must resolve inside the fixture, so review stays bounded by the smoke change however much history the caller's branch has accumulated. `review-fixture` reviews the fixture's own commit when `--set write=false` skips the writer, and `fixture_base` names the fixture commit the write node starts from. The earlier `smoke-write` and `smoke-review` names and the staged fixture are gone, and the verdict counts only when the nonce appears in both read and review results. `--set diff_base=BASE` still overrides the review base and its source is shown.
