## Fixes

- A legacy slot-root writer reservation now fences only the attempt it names for recovery evidence and recovery acquisition, so a successor with no reservation of its own settles as provably absent instead of carrying the previous attempt's fence. Writer admission still refuses any retained legacy slot-root record, because a provider can outlive its guardian's slot lock. A record that cannot be read, decoded or validated, including one with a wrong schema version, still counts as retained, and a device renumbering across a reboot does not turn another attempt's record into an every-attempt fence (#2433).
