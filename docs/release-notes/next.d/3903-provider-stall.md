## Fixes

### Lanes and settlement

- A live provider that stops emitting output is now visible instead of reading as `running` forever. `providers.<id>.stall_after_seconds` (compiled default 1800 seconds, `0` disables) measures from the last output or, before the first output, the provider start; queued time is excluded; the threshold and its layer appear in `run --explain` and on the lane's recorded limits. `status --json` carries `stalled: true` with the last-event time, the chair's digest prints `stalled last_event=<time>`, and `wait` ends with the `stalled` outcome (exit code 6) without claiming settlement. Detection only warns (`PROVIDER_STALLED`), so a slow but healthy provider is never stopped on a guess. `providers.<id>.stall_policy` is opt-in: `report` (default) warns only; `steer` queues one steering turn; `retry` stops the provider through run-side custody after warning and advances to the next route within the graph retry budget; `fail` stops it and settles with typed `provider_stalled`. (#3903)
