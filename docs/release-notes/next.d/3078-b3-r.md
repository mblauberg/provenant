## Breaking changes
### CLI and install

- **The 1.x cut-over needs the 2.0 installer.** Run `install.sh --upgrade --reset-state` after stopping lanes and closing other sessions; a captured 1.x upgrade refuses without prompting. Read the dropped and kept lists and the [install runbook](../../runbooks/install.md#bootstrap-and-upgrade) before proceeding. (#3078)
- Removed the obsolete `config migrate` command. `config check` reports retired settings for manual repair, as required by the CLI contract.
