## Fixes
### Lanes
- A new sourced knob `lanes.pr = never | draft | allowed` governs pull-request writes from a lane. It defaults to `never`, so a leaf implement writer lane no longer opens a PR (including against the wrong base); the chair publishes after settlement. The lane's `gh` tool refuses PR mutations and mutating forge calls under `never`. Under `draft`, it adds `--draft` to `pr create`, permits edit, close, comment and review, and refuses other PR writes and forge writes. Both restrictive policies refuse unknown PR subcommands until classified; `allowed` forwards unchanged. The effective value and its source appear in the writer preamble, the launch receipt and `run --explain`. Set it with `provenant config set lanes.pr draft` or `--set lanes.pr=allowed`. The control applies to the lane's tool policy, not to host-side delivery. [#3989](https://github.com/mblauberg/provenant/issues/3989)
