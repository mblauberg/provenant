# Provenant v1.6.12

Released 7 November 2026.

Version 1.6.11 could not be installed over real state because its upgrade check counted finished graphs as pending; 1.6.12 fixes this, so upgrade straight to 1.6.12. Before upgrading, finish pending graphs, drain live lanes and port user presets to templates by hand; if upgrading from 1.6.10, also read the [1.6.11 breaking changes](v1.6.11.md#breaking-changes).

## Additions

- `pr-reconciler` observes pull requests and writes proposed review, repair and landing decisions, daily digests and local escalations. It can generate a launchd supervisor configuration; automatic action remains disabled pending live observation and restart evidence. See the [operator runbook](../runbooks/pr-reconciler.md) (#2873).

## Fixes

- Allow upgrades past settled older graphs and orphaned child-store lanes while still requiring live work to drain.
- Allow upgrades past orphaned root lanes and settle never-started attempts from their exit evidence.
- A waited graph submission stops retrying unaccepted admission when the caller's wait expires, retaining the lock cause and recovery guidance. A held writer lock refuses immediately; registry contention remains retryable (#2823).
- Record a warning on a repair writer when no separate model family is available (#2843).
