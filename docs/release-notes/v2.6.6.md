# Provenant v2.6.6

Released 22 November 2026.


## Fixes

- An agy account whose recorded offer list lacks the requested model is no longer listed as ready by `provenant route resolve`, and an unpinned resolution does not select it when its usage probe has not run. The exclusion names the account, model and recorded offers. An explicit `--account` pin is kept with a warning and still attempted. The synthetic `local` quota row no longer appears as a route candidate once an adapter has registered accounts (#3762)
- `provenant quota tick` now records a positive account readiness observation when a probe succeeds with figures. `provenant quota show` no longer reports "unknown (not probed)" and advises another tick that would repeat the same result. A deferred refresh still reports no probe, and a successful probe with no figures remains informational
- `provenant console overview` reports `runs: empty` with zero counts on a host with no run store, matching `console board` and `console tree`, instead of reporting run state as unavailable. The console no longer says "Run state is unavailable here" when the run scan is merely partial: it reports that counts may be incomplete
