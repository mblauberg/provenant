# Provenant v1.11.0

Released 13 November 2026.

This release makes lanes behave like native sub-agents. Every lane kind, read-only included, now runs without the macOS sandbox by default, and writers commit and publish their branches. A lane stopped on its token budget keeps its commits, and OpenCode failures explain their cause and fall back to another route. Read Behaviour changes before upgrading.

## Behaviour changes

- Unsandboxed lanes inherit your environment, PATH, tool caches and credentials in place while retaining the selected provider account. Launches skip sandbox-only skill copies, tool discovery, credential inventory and private Cargo setup; sandboxed inventory warnings are combined into one actionable line.
- Lanes now run unsandboxed by default for every lane kind, including read-only lanes, so sub-agents can run natively like a CLI started by hand. The default `[domains.run] sandboxed_routes` list is now empty by default (users can configure routes to sandbox). Explicit `--no-sandbox` / knob `off` takes precedence over route, narrowed-network and Provenant parent floors, emitting a warning naming dropped restrictions. An operating-system inherited sandbox (Seatbelt) cannot be removed and is honestly reported as effective. Run records and receipts now track requested and effective sandbox mode and its source. See [lane sandbox mode](../runbooks/configuration.md#lane-sandbox-mode).
- Test doctrine prioritises extensible, flexible and reliable tests: public-boundary invariants and property-style checks replace rigid tests, exact count or string pins, and brittle example snapshots. Regression tests are minimal (at most one small check per real defect only where no invariant covers it), failing tests that pin implementation details are rewritten as invariants or deleted rather than bending production code, and deleting redundant tests is established as normal work across `skills/test-design`, `MAINTAINING.md`, and review lenses.

## Additions

- `worktree create` and writer `run --branch/--base` can run project-configured setup commands once in each new worktree. Setup failures warn and leave the worktree usable; see [configuration](../runbooks/configuration.md#worktree-setup) (#3078).

## Fixes

- Command help now shows every public flag. `help --all` renders each public
  command with its options.
- `reconcile --abandon ATTEMPT --reason TEXT` can clear retained queued lanes that never dispatched, preserving their evidence and reason. Attempts with process evidence or writer custody remain protected (#3183).
- Writer lanes stopped on their token budget preserve native Git commits when publishing their branch, without creating a snapshot when the worktree is clean (#3207).
- OpenCode provider authentication and quota failures now explain the cause and allow route fallback; unsupported model efforts are dropped with a warning (#3245).
- Detached provider services no longer inherit lane writer or port leases. Cleanup deadline warnings identify observable processes with the writer lock open and give a reconcile action; unresolved custody remains fenced (#3248).
- Graph recovery replay now restores `parent_sandboxed` and carries `admitted_by` when reconstructing an accepted attempt specification after a host crash, matching the sealed request digest and preventing false `OperationConflict` errors (#3249).
- Retries, quota redraws and background continuations retain access to the host GitHub login. Lanes warn when GitHub tools or credentials are unavailable.
- Writer results report the effective committed head and avoid calling committed work a no-work stop.
- Failed local pre-push gates now report a redacted tail of command output.
- Fan-out prompts include their item, large comma-separated lists warn, and status waits return when graphs pause. Briefs can mention placeholder syntax.
