# Provenant v2.4.0

Released 19 November 2026.

## Breaking changes

- The lane supervisor keeps only what providers cannot do: start, exit
  watching, process-tree cleanup, durable records and the writer, credential
  and authority boundaries. It no longer samples CPU or disk per lane, tracks
  output silence, spares processes by command name or re-checks the provider
  executable before spawn, and it scans cleanup holders once per guardian
  rather than every 30 s. Status no longer reports provider silence. (#3566)
- `lanes.silence_seconds`, `lanes.supervision` and the `GUARDIAN_DISK` policy
  are removed; delete them from config. (#3566)
- Process-tree sampling is off unless something needs it: an admission class
  with `memory_per_slot` turns it on every 5000 ms, and
  `domains.run.resource_sample_interval_ms` (1..=60000) sets it explicitly;
  `provenant config show --full` names the source. When it is off,
  `PROVENANT_PROCESS_TREE` is unset. (#3566)
- `lanes.cargo_target` now defaults to `private`, and the `shared` value is
  removed. `provenant config check` reports a `shared` setting and the
  default applies. (#3561)

## Additions

### CLI and install

- `provenant worktree seed-target PATH` seeds a checkout's private Cargo
  target from the host seed and prints it for `CARGO_TARGET_DIR`, so a chair
  or person can build warm outside a lane. (#3561)

## Fixes

### Lanes and settlement

- A lane's own background processes no longer outlive it. When the provider
  exits, for any reason, the supervisor ends its recorded descendants and any
  process carrying the attempt's sandbox mark, re-checking each identity before
  every signal. Recovery after a lost supervisor does the same from the
  recorded identities. The exit records one "killed N surviving descendants"
  warning. Processes found only by working directory are never signalled.
  Background services an unsandboxed lane starts (for example a compiler-cache
  server) now end with the lane. (#3545)
- Worktrees no longer serve each other stale Cargo artifacts. Each worktree
  gets its own target in its lane cache, cloned warm from the repository's
  host seed with every dep-info aged, so workspace members rebuild once from
  the worktree's own sources while registry crates stay fresh. The shared
  target let a worktree with older sources reuse another branch's artifacts
  and report symbols missing that exist in its source. Where the filesystem
  cannot clone, the target stays unseeded and the host warns once.
  `provenant gc` lists the old `provenant-shared-cargo` directories and
  `--apply` removes those not in use. (#3561)
- Retained custody no longer polls the host every 20 ms while it stops a
  lane's survivors: each stop takes at most three censuses and waits on exit
  watches between signals, and an exit that lands between a census and its
  watch now counts as an event, so the writer lock is released promptly.
  (#3566)
- A configured process-tree sampling interval now takes effect; guardians
  could not read config and always sampled every 5000 ms. (#3566)

### Accounts, quota and routing

- A project binding read that loses repeated races with a hint update now
  reads once more under the shared binding lock instead of reporting the
  binding invalid. (#3570)
