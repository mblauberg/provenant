# Provenant v1.6.20

Released 8 November 2026.

Cloud placement set on a run or graph node now reaches submission, and `--model` accepts a bare model name. There are no breaking changes.

## Fixes

- `provenant run --model` accepts a bare model name, such as `claude-sonnet-5-5`, when exactly one catalogued provider offers it. A name that several providers offer is refused with the `provider/model` forms to choose from, and an unknown name is refused with the form to use. The `provider/model` form is unchanged.
- A run or graph node with `attempt.cloud` set now submits its cloud job. It was refused at launch with a bare invalid input because the task had no source commit; the launch now pins the checkout commit and reuses it after a restart. A refused placement names the field and the reason.
