# Provenant v1.6.23

Released 9 November 2026.

Agy lanes can now reach the native keychain they need to sign in, and a cloud job whose submission outcome is unknown can be abandoned.

## Fixes

- Agy lanes permit the native keychain client and IPC for login and isolated
  accounts. Authentication diagnostics distinguish explicit timeouts, missing
  sign-ins and keychain refusals, and report when the CLI supplies no cause.
### Telemetry and providers

- `provenant reconcile --abandon` now settles cloud records created before source pinning, which have no commit and no saved job, and keeps the existing evidence and remote-session warning.
- A cloud submission the provider definitely refused now redacts credentials from the saved failure detail, as the uncertain path already did.
