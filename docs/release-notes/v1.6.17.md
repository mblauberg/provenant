# Provenant v1.6.17

Released 8 November 2026.

Review lanes on a pinned commit start again, supervisors use far less CPU while their lanes wait, and refusals before launch now name their real cause. There are no breaking changes.

## Fixes

- `run --file` now passes file briefs to the lane regardless of their name or location, and refuses empty or unreadable files before launch.
- Lane supervisors use less CPU when children start and exit rapidly (#2886).
- Review lanes can now read their pinned commit checkout at startup; on 1.6.16 Codex review lanes failed with `Operation not permitted` on macOS.
- `output` now lists a writer lane’s changed files under its worktree.
- Lane launches now summarise credential inventory warnings instead of printing a line for every unresolved link or traversal limit.
- `quota` now reports that account quota must be read from the chair's session when invoked inside a lane.
- `run` reports a busy provider update instead of a disclosure denial and considers other eligible providers in the configured pool. If every provider is busy, it refuses after the bounded wait; provider updates retain their timeout even if the update worker exits unexpectedly.
- `run --file graph.json --route senior` preserves the graph’s tasks and dependencies while applying the route override (#3023).
