# Provenant v1.10.0

Released 12 November 2026.

This release runs writer lanes on trusted routes without the macOS sandbox by default, so they share host build caches; the OpenCode Zen tier, read-only and narrowed-network lanes, and lanes started by a distrusted lane stay sandboxed. Read Behaviour changes before upgrading.

## Behaviour changes

- Writers on trusted routes now run without the macOS sandbox, like the same CLI started by hand, so they share host build caches. Read-only lanes, lanes with a narrowed network, routes listed in `domains.run.sandboxed_routes` (the OpenCode Zen tier by default), and lanes that a route- or knob-sandboxed lane starts or adds to a graph stay sandboxed; `run --sandbox` / `--no-sandbox`, `attempt.sandbox` and the host `lanes.sandbox` knob override the rest. Lanes see `PROVENANT_SANDBOX=on|off`, `status` and receipts record the mode, hosted-cloud keys are stripped from every lane's environment, and `domains.run.sandbox_cache_reads` gives sandboxed lanes read-only host cache paths. See [lane sandbox mode](../runbooks/configuration.md#lane-sandbox-mode) (#3246).
