# Provenant v1.6.18

Released 8 November 2026.

Writer lanes launch again on projects whose `writer_writes` names a directory inside another checkout, and named routes now try their remaining members when the first is excluded before launch. There are no breaking changes.

## Fixes

- Writer lanes launch again when `[domains.run] writer_writes` names a directory inside another checkout, such as the primary checkout's ignored `.agent-run/locks`. Since 1.6.16 such a project refused every writer with "confinement permission overlaps a protected path". The configured directory is now exempt from that checkout's write denial, and the rest of the checkout stays read-only. A `writer_writes` entry that is the checkout itself, encloses one or reaches Git metadata, and any graph write root inside another checkout, are still refused.
- A named route such as `senior` or `junior` no longer stops when local preparation excludes its first candidate. `run` tries the route's next permitted member, whatever the exclusion, and `skipped_routes` lists every excluded candidate with its cause. A candidate is reported `disclosure_denied` only when the disclosure policy refuses it; a missing confinement plan reports `confinement_unavailable` with its guard. `domains.routing.settlement_retries` bounds launched attempts, not candidates that never launched.
- Claude cloud targets work with the current `claude --cloud` CLI: `--environment` is passed only when the target names a self-hosted pool, and the session id is read from the CLI's `Resume with` line. A Codex cloud target without an environment is refused before submission.
