# Provenant v1.5.1

Released 3 November 2026.

This patch release fixes lane sandbox gaps, so zsh here-documents work and read-only lanes can build Swift and Cargo projects in scratch, and lets Gemini Flash and OpenCode free routes take writer work. Review councils and planned graphs now carry on after a lens or planner fails, graph nodes enforce deadlines, and `provenant quota` reports a missing agy keychain clearly.

## Behaviour changes

- Writer lanes can use Gemini Flash (`agy/gemini-3.8-flash`) and OpenCode routes with a `-free` suffix. These routes are no longer restricted to read-only lanes, and by default they no longer need specific answer section lines in their output (#2646).
- A review council continues when a lens fails or returns no valid findings block. Verification and synthesis run on the surviving lenses, the failed lenses are listed as `unavailable <id>: <reason>`, and synthesis marks the result degraded when fewer lenses survive than the tier minimum (#2540).
- A graph node can carry `deadline_seconds`, which becomes its lane timeout, capped by `limits.graph_timeout_seconds`. A lane that exceeds it fails the node with `deadline_exceeded`, and planned `big-batch` lanes now enforce their `budget_seconds` this way, shown by `--explain` (#2556).
- When a planner node fails, including before launch, the run continues with the preset's static stage instead of failing, and `provenant output` names the planner fallback and its reason. Rerunning with `--plan off` is no longer needed (#2557).

## Fixes

- `provenant run --manifest` with many lanes finishes faster: a 20-lane manifest took about half the wall time in testing. Bundled routing data is parsed once per process, and each lane's result is read without re-resolving the project (#2652).
- Read-only lanes can run `swift build`, `swift test`, Cargo builds and Rust doc-tests, with build output, caches and SwiftPM manifests placed in lane scratch. Reviewers no longer need to fall back to static review when the worktree is protected (#2542).
- Shell here-documents and here-strings in zsh commands, such as `python3 - <<'PY'`, work inside lanes. Lane scratch now holds the temporary files that zsh previously tried to create under `/tmp` and was refused (#2655).
- `provenant quota` reports an agy account whose isolated keychain is missing as `KEYCHAIN_UNAVAILABLE` instead of an authentication failure, with a `repair` line naming the expected keychain path and how to re-register or recreate it. `provenant hosts doctor` lists the same check for every registered agy account, and the menu bar app shows the account as needing action and shows any unrecognised status as unknown instead of failing to read the whole quota report (#2645).
