# Provenant v1.6.15

Released 8 November 2026.

In 1.6.14, several writer launches started at once with a short `--wait` could fail; 1.6.15 gives launches their own deadline, so `--wait` only limits how long the command waits. This release also improves graph relays and retries and adds scheduled tracker sweeps.

## Additions

- `steward` provides junior-tier tracker sweeps that propose duplicates on the newer issue and report parent suggestions and thin bodies. Enable scheduled proposal sweeps per repository in the host config; `provenant tick` keeps one scheduled run at a time and reports launch failures (#2977).

## Fixes

- Short `run --wait` values no longer cut short the writer registry lock wait.
  Top-level and child writer bindings have a separate launch allowance, configured
  by `domains.fabric.graph.writer_launch_seconds` (default 55 seconds). A launch
  can block beyond a short settlement wait. One deadline covers provisioning,
  existing worktrees, later custody and registry checks, and launch retries.
  Child relays honour configured allowances longer than 55 seconds and return
  the launch receipt or named refusal. Settlement expiry leaves accepted attempts running.
- Concurrent writer launches avoid inspecting sibling checkouts and recheck transient
  held paths within the launch allowance before refusing a live writer.
- Graph relays retain unresolved writer checkout fences after a launch deadline expires, reconcile them on a fresh bounded attempt, and continue serving unrelated operations.
- Nodes refused before host acceptance can be retried after a graph settles, once the cause is corrected. Retry reports actionable graph target errors and documents graph and node selectors. Graph status JSON includes the node rows shown in full status.
- Child output reads stay within the calling lane's graph when graph and attempt IDs collide.
- Writer children in another project can continue after quota fallback or retry. Existing same-project writers retain their saved request identity on replay after upgrading.
- Agents inside lanes can read their graph and children's output, status and trace through the host relay. Children can select another project, including its registered writer worktrees. Launch refusals retain actionable causes without exposing host journals or credentials.
- Review launches can pin a subject and base with `--set`, fetching remote branches on the host before supplying the review diff.
