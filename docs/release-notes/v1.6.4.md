# Provenant v1.6.4

Released 5 November 2026.

This release fixes the `review-council` synthesis failure that remained in 1.6.3, whose notes said the council was restored: a council still failed when its verifier reused short finding ids across lenses. It also tells lanes to keep working until the brief is finished. Read [Breaking changes](#breaking-changes) before upgrading: graphs from an older release cannot be resumed, so finish or cancel them first.

## Breaking changes

- **Lane JSON uses one projection.** Update consumers of `status`, `output`, `cancel` and `land` to read the shared identity, state and retry-lineage fields and structured paths (#2353).
- **The `--deliver-remote`, `--deliver-branch` and `--open-pr` flags are removed.** Use `--deliver push`, `--deliver integrate:<branch>` or `--deliver pr` for host delivery (#2828).
- **Lane build seeding requires `tools/front-door/rust-toolchain.toml`.** Move a fixed release pin from the old `rust-toolchain` file into its `[toolchain]` table (#2828).
- **Graphs started on an older release cannot be resumed after upgrading.** Finish or cancel them before upgrading. (#2901)
- **Error codes use uppercase spellings.** Update clients matching `launch_unknown`, `owner_local_only`, `unsupported_owner`, `console_app_unavailable`, `reconcile_incomplete` or `cli_failed` to match `LAUNCH_UNKNOWN`, `OWNER_LOCAL_ONLY`, `UNSUPPORTED_OWNER`, `CONSOLE_APP_UNAVAILABLE`, `RECONCILE_INCOMPLETE` or `CLI_FAILED` respectively (#2828).
- Prepared graph operations no longer retry submission using the older input
  without task context. Finish or cancel active graphs with the old binary and
  wait for their attempts to settle before upgrading (#2828).
- Checkpoints containing pre-node-ask loop state are now unreadable. Finish or
  cancel their graphs with the previous release before upgrading; cancelling an
  unreadable record only retires it and does not settle attempts or inbox
  requests (#2828).
- Checkpoints missing expansion topology are no longer reconstructed. Finish
  those graphs before upgrading; cancel an unreadable record and start a new
  graph after its attempts and custody have been settled (#2828).
- Graph fallback history that switched routes after a launch is no longer read.
  Finish those graphs before upgrading; a new route still requires evidence of
  local preparation and released custody (#2828).

## Behaviour changes

- Lanes are now told to work until the brief is finished and to keep `stopped_early` for when they cannot carry on in this session. The old wording offered `stopped_early` as its only example, so writers ended their turns after a slice with work they could still do.
- `fabric graph wait` observes a graph until it settles or the wait expires. A preset still in flight now reports `waiting` instead of `timeout` (#2513).

## Fixes

- `review-council` no longer fails at synthesis with "upstream finding F1 needs exactly one disposition" when a verifier reuses short finding ids across lenses and omits the composite prefix from `propagates`. A marker resolves when it is a colon-delimited suffix of one finding's marker, and an ambiguous one still leaves the finding independent with a warning. 1.6.3 restored the council only on routes that reached synthesis without this shape.
