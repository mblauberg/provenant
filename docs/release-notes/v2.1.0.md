# Provenant v2.1.0

Released 18 November 2026.

This release adds provider model discovery and improves lane settlement, routing and graph recovery. The GC command and configuration now use durations; update existing idle settings before upgrading.

## Breaking changes

- Replace `gc --idle-days N` with `gc --idle Nd`, and replace `gc.idle_days` with a duration such as `gc.idle = "6h"`; the idle default is now six hours. (#3420)

## Behaviour changes

- Unrooted publication, overlapping scratch paths, stale readiness, unknown quota identity, duplicate route alternatives and uncatalogued effort warn by default; their policy settings can still refuse. Credential, authority, Git isolation and data-integrity boundaries still refuse. (#3371, #3464)
- Lane verification defaults to targeted checks on a shared warm Cargo target, and Cargo scope checks warn and proceed by default. (#3414, #3440)
- Attempt scratch remains available after release and is collected when its owning work finishes. Merge cleanup targets the finished work; low-space launches trigger a background sweep. (#3420)
- Delegation and review guidance favours proportionate work, continuous integration and overridable reviewer preferences. Security review focuses on credentials, authority, other writers’ uncommitted work and data integrity, allowing shared lane notes, caches and resources. (#3449, #3446, #3473)

## Additions

- `pr status` batches multiple pull requests, and `ci failures` extracts actionable nextest and Cargo failures with compact or JSON output and quota-aware cached reads. (#3421)
- `scripts/collate-release-notes` warns when a patch release contains breaking changes, so the owner can choose a minor or major version. (#3394)
- `quota tick` discovers provider models for installed adapters with registered accounts and enabled probes, retaining the last successful listing when a probe fails. Shipped pools follow the latest matching model version; explicit user choices stay pinned. `route list` and `route resolve` show model sources; set `knobs.quota.model_discovery = false` to disable discovery. (#3418, #3455)

## Fixes

- Cargo commands run from the repository root use the same pinned Rust toolchain as commands run from `tools/front-door`. (#3470)
- Concurrent writer launches wait for the repository lock within the caller’s budget instead of immediately settling as blocked. (#3393, #3439)
- Writer launch and settlement accept a completed rebase that left `REBASE_HEAD` behind, while settlement refuses a worktree with a bisect in progress. Recovery guidance names the current branch head separately from the retained private commit. (#3404)
- Clean provider exits with incomplete identity evidence now settle under the configured policy, warning by default; confirmed identity conflicts still refuse. (#3459, #3463)
- `provenant land` refuses draft pull requests before candidate gating and preserves GitHub’s response message on HTTP 405 merge refusals. (#3385)
- Registered accounts with HOME-rooted or shared credential stores can launch lanes without exposing sibling credentials. Selected authentication uses exact credential endpoints; dedicated stores and relocated Codex homes retain whole-store protection. Symlink targets stay protected, conflicting writes refuse, and refusal diagnostics name the most specific declaration and its origin. (#3392)
- `accounts register` accepts nested agy HOME roots while refusing shared state or credential stores. Pools can use both the local login and registered accounts; recorded agy refusals expire within five minutes so stale reset estimates cannot block working models. (#3423)
- Landing skips unreadable graph review sources, including enumeration failures, and reports warnings naming the graph or project while allowing other independent approvals to qualify. Corrupt checkpoints remain visible through status and tick reporting, including after rebuilding the pending index. (#3400)
- Graphs with redacted prompts reload, resume and advance with matching checkpoint digests. Credentials in graph identities and keys are rejected, and template expansions are checked for credentials assembled from separate fragments. Resume by source path or document hash uses the journal’s sealed execution, preserving admitted template metadata and pinned bases. (#3400, #3401)
- Provider output keeps quoted credentials masked when they overlap known secrets, masks credential suffixes after `[REDACTED]` followed by a backslash, and continues capturing output after large redactions. (#3387, #3386, #3400)
