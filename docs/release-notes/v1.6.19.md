# Provenant v1.6.19

Released 8 November 2026.

Claude writer lanes that commit but end on a tool call no longer settle as failed, hosted Claude cloud placement no longer needs an environment, and invalid graph input names the field to fix. There are no breaking changes.

## Fixes

- A Claude lane whose final result event is empty, such as when its last turn was a tool call, now keeps its last non-empty assistant message as the result and records that in the settlement reason. A writer that exits cleanly with no final message at all settles as `review_required` with its commit kept, not `task_failed`. The "findings block missing or invalid" warning no longer appears on nodes that neither require findings nor review; review and findings-required nodes still fail on a missing block.
- Read-only cloud placement can omit the environment for hosted Claude, and invalid graph and attempt fields report their path and reason without echoing the value or user map keys (#2889). `docs/runbooks/providers.md` shows the working `--set attempt.cloud=...` form.
