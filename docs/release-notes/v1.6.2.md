# Provenant v1.6.2

Released 5 November 2026.

This release repairs two breaks in 1.6.1: plain launches failing on stores upgraded from earlier releases, and path denials failing finished lanes and `review-council`.

## Fixes

- The pre-push hook protects the default branch when a remote branch alias points to it (#2854).
- Upgrading from a release before 1.6.1 no longer breaks plain launches: a run store at version 7 now upgrades on open, where it used to stay behind and fail with `IO`. A run store failure now names its cause on the local host (#2908).
- A sandbox path denial no longer fails a finished lane. The note moved from the provider's answer to the settlement reason, so its handoff still parses, which restores `review-council` subjects and writer lanes that were ending early. A published reason now stays within the terminal-evidence limit (#2910).
