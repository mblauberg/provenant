# Provenant v2.2.0

Released 18 November 2026.

Lanes in a project now share one warm Cargo target by default, and gc reclaims idle private lane caches. This release also adds notes and resumable event delivery, and fixes graph retry.

## Behaviour changes

- Building from source requires Rust 1.100.0.
- Default `lanes.cargo_target` to `shared`, giving lanes in the same project a shared warm Cargo target directory under the host cache instead of private copy-on-write clones. Set to `private` or an absolute directory to override. (#3442)

## Additions

- Share observations with `provenant notes add` and read deltas with `provenant notes read`. Notes retain host provenance, free-form tags, project/graph/subtree scopes and append-only corrections; replay and disclosed read caps preserve history. (#3443)
- `provenant events --follow --json --consumer NAME` resumes lane, graph and forge notifications from a stored cursor. Waits use the shared journal and retain the last known outcome on timeout. [Delivery contract](../specs/lane-contracts.md#observation-events). (#3458)

## Fixes

- `provenant retry NAME` on a failed graph retries or fails instead of exiting 0 without acting. Carried exclusions are normalised to `adapter/id`, and an exclusion that no longer parses is dropped with a warning. (#3456)
- On macOS, ending a provider's process group no longer fails with EPERM when only exited processes remain in the group. (#3514)
- Reclaim idle private lane Cargo caches during full and low-disk sweeps while protecting active owners and held locks. GC previews use bounded cache measurements. (#3488)
- Worktree owner claims wait within their lock budget for observation probes, avoiding spurious busy refusals during concurrent launches. (#3477)
- `provenant run` avoids oversized checkpoints when graph resolver values repeat large briefs, preserving the original text on reload. (#3477)
