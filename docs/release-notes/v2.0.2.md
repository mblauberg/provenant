# Provenant v2.0.2

Released 15 November 2026.

Provenant 2.0.2 improves provider routing and lane reliability across Cursor, Agy and other agent workflows. It adds configurable model scopes, fixes Cursor result capture and preserves the requester's toolchain path across lane retries.

## Behaviour changes

### Accounts, quota and routing

- Cursor automatic routing uses only its own Composer and Grok models, each at the lowest weight to stretch its monthly allowance. Auto remains available for explicit pins, but is not routed because Cursor does not report the model it chose. Provider model scopes control routing, while out-of-scope pins warn by default and can be configured to refuse or proceed silently. Supported Cursor effort levels are passed through in the launch model name. (#3316)

## Fixes

### Accounts, quota and routing

- Reject overlapping account directories and diagnose existing registrations; avoid spurious domain warnings in run previews. (#3310)
### Lanes and settlement

* Prevent duplicate answer capture in Cursor lanes by emitting assistant text as fallback answer events and using the result event for the final answer (#3311).
### Lanes and settlement

- Preserve the requester’s toolchain PATH when a supervisor advances a lane. (#3315)
