# Provenant v1.6.5

Released 6 November 2026.

This release lets a graph finish with the fan-in members that succeeded, so one exhausted reviewer no longer blocks a whole review. It also moves provider rules into the registry, and adds continuations and retention fixes for lanes and graphs.

## Behaviour changes

- GC defaults to collecting eligible `target` directories for Cargo projects without a project-specific GC entry. An explicit entry overrides the default (#2834).
- GC can reclaim ignored output in idle unknown-writer worktrees after a complete process census finds no holder, while keeping the worktree (#2834).
- Terminal graph checkpoints are retained for 90 days by default; `gc.graph_checkpoint_days` changes the retention period. Collection also removes matching scratch graph documents, and older telemetry reports can show a missing checkpoint (#2868).

## Additions

- Writers queue for the repository Git setup lock in arrival order. `domains.fabric.lanes.setup_lock_wait_seconds` sets the wait bound from 1 to 14400 seconds; the default is 14400. A timeout reports `SETUP_LOCK_TIMEOUT` and how to retry or adjust the bound (#2891).
- Writer presets offer an overridable writer tier, and graph previews report an advisory tier mix (#2720).
- Fan-out presets can declare a minimum number of successful branches, and settled graphs report their outcome.
- Fan-out synthesis can take individual branch briefs and routes, with a separate synthesis route.
- Dispatch and graph nodes can require an adapter-owned skill location during route selection and launch (#2819).

## Fixes

### CLI and install

- GC previews reuse a process census and Git worktree inventory across worktrees, avoiding repeated enumeration (#2835).
- SessionStart keeps completed lane and worktree rows when inventory reaches its time budget, and reports how many were skipped (#2835).
- GC skips per-worktree Git probes, status and index reads outside its cleanup scope, checking candidates under writer exclusion before cleanup (#2835).

### Lanes and settlement

- SessionStart keeps the lanes and worktrees it has inspected when its inventory times out and reports how many records it skipped (#2835).
- A held worktree writer lease remains visible as busy when the process census also sees a process in the checkout (#2877).
- Stopped writer merges retain their index and merge parents for a continuation; an unresolved import names the retained worktree and its recovery command (#2890).
- **Lane continuations respect their owner.** Continuations require the prior owner to be settled, observe cancellation during Git setup, and retain the exhaustion reason after recovery (#2903).
- Continuations retain access to an explicitly selected worktree with an unchanged earlier owner. Terra writers have a longer default continuation allowance. Lane results distinguish a pending continuation from exhausted continuations (#2903).

### Accounts, quota and routing

- Human route previews no longer display instructions intended for a launched model (#2468).
- Route previews describe readiness and distinguish missing or expired observations from provider refusals (#2468).
- Quota and hosts doctor show the same account-scoped readiness evidence and observation time (#2468).
- Route lists and resolution show recorded model-scoped readiness for matching accounts (#2468).
- Hosts doctor identifies installed adapters without account observations as unknown (#2468).
- Hosts doctor checks local sign-in status for installed Codex and Cursor adapters without recorded account observations (#2468).
- Quota ticks can refresh missing readiness records before a fresh quota snapshot expires, using the configured panel interval (#2468).
- Providers registered with Provenant can resolve, prepare and report quota without a duplicate built-in identity entry (#2749).

### Pipelines and graphs

- Read-only graph nodes can move to another configured route after a launched attempt hits an authentication or usage limit, within their retry budget (#2882).
- Tick reports a missing graph worktree once and continues advancing other graphs (#2907).

- Worktree inventory and cleanup treat an unresolved retained writer import as occupied even after its writer lock is released (#2877).
