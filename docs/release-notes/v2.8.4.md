# Provenant v2.8.4

Released 24 November 2026.

Provenant 2.8.4 routes batch items and graph nodes by one full catalogue model id, so a short or slash-containing model routes exactly like `run implement --model`. It also makes `worktree create` reuse a clean worktree already on the requested branch, and keeps stop publication intact when concurrent launches move remote tracking refs.

## Fixes

- Concurrent `run implement` launches no longer lose stop publication when an unrelated remote tracking ref moves: delivery and stop publication now share one coalesced, locked refresh, so a racing ref transaction is tolerated instead of dropping the binding. (#3853)
- `provenant worktree create` now warns and reuses a clean worktree already on the requested branch and at or ahead of the requested base, returning its path, while an unrelated base or dirty tree refuses with the existing path, branch and reason named. (#3852)
- A batch item whose `model` contains a slash now keeps the full adapter/model id and routes exactly like `run implement --model`, instead of dropping its adapter's first segment during preparation. Graph routes now carry that one full catalogue id from admission through preparation, so exact-model tiers and node route tables cannot be split or re-parsed, and a declared route equal to a ladder hand-off is not offered twice. (#3851)
- Every host path that admits graph nodes (submission, document edits, relay children and planner fragments) resolves a model written without its adapter, such as `opencode/hy4-flash-free` on the `opencode` adapter, to its full catalogue id once against the effective catalogue. A model the catalogue does not list is kept as written and reported with a `ROUTE_MODEL_NOT_CATALOGUED` warning. (#3851)
