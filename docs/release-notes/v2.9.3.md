# Provenant v2.9.3

Released 24 November 2026.

Provenant 2.9.3 lets `reconcile --abandon` settle a lane whose writer checkout was removed, while still refusing when a process remains inside the deleted tree. `run smoke` without a writer now skips its write node, and a stray remote-tracking ref no longer blocks a writer branch.

## Fixes

- `provenant reconcile --abandon` can settle a lane whose writer checkout has been removed. The census places each process against the removed path by the identity of its nearest existing directory, so an unreadable system process elsewhere no longer blocks abandonment, while a process left in the deleted tree, including one whose cwd is the removed root, still does. (#3897)
- A writer branch is no longer refused because its name collided with a remote-tracking ref under a remote alias that does not exist, such as a stray `refs/remotes/origin/w1ci/smoke`. Configured remotes whose names contain `/` still match, and the refusal names the colliding ref. (#3901)
- `provenant run smoke` without a writer no longer fails on the write node it said it would skip. A node whose `when` condition is false is never bound to a writer worktree, so it settles as skipped while the read and review nodes still run. (#3899)
