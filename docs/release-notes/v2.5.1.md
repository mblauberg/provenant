# Provenant v2.5.1

Released 20 November 2026.

Provenant 2.5.1 replaces the withdrawn 2.5.0, which refused every lane launch on hosts that still held custody records from 2.4.1. It carries all of 2.5.0, plus protection for unusable sibling custody and refusals that name the failing path.

## Fixes

- Unusable sibling writer custody is protected and reported while unrelated launches proceed; install and upgrade warn about retained schema-1 guardian records. (#3681)
