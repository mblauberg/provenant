# Provenant v1.6.13

Released 7 November 2026.

Version 1.6.12 could refuse launches started at the same moment with an upgrade drain error; 1.6.13 fixes this. The release also improves launch refusal details, interrupted delivery recovery, quota reporting and lane recovery.

## Fixes

- Allow simultaneous launches after a clean upgrade drain check and avoid repeating the scan on later launches. Refusals now identify pending work.
- Refused launches now report the redacted cause in command results and graph status, without pointing to a lane receipt when no attempt exists. Automatic dependency setup failures warn and let the writer continue.
- Writer launches now name the invalid graph node and missing worktree requirement, infer writer access from an explicit worktree target, and direct launch settings to their supported flags.
- Recover interrupted delivery pushes by checking the remote before retrying.
- Report typed launch refusals and partial graph launches while preserving route fallback.
- Record provider quota refusals when they arrive so recovery preserves the original observation.
- Codex writer token budgets now stop a lane after a completed turn passes the limit, while preserving uncommitted work where settlement permits.
- `reconcile` settles failed lane Git imports after the guardian exits, preserving their evidence and retained objects. `status` and `output` warn that commits may not have reached the branch and show the head commit and retained object location when available. Busy records no longer hide progress on other records or remain in the report after settlement.
- `run --mode worktree-write --worktree W` accepts launches from inside the selected worktree, including its subdirectories.
- `provenant quota` shows every configured account in its compact view, and expired Claude logins first suggest a short interactive session with the account's config directory.
