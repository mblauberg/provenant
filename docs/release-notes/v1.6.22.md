# Provenant v1.6.22

Released 8 November 2026.

Claude cloud placement from a graph now submits under the pseudo-terminal it needs, and a cloud job whose submission outcome is unknown can be settled with `provenant reconcile --abandon`. There are no breaking changes.

## Fixes

- Claude cloud submissions from a graph now run under the pseudo-terminal they need. A submission whose outcome is unknown keeps a bounded diagnostic, and `provenant reconcile --abandon` settles it with a warning that a remote session may still exist (#2889).
