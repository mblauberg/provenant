# Provenant v2.0.5

Released 18 November 2026.

This release makes implementation planning opt-in, makes retry and steer resume reliably, and closes credential leaks through quoted values in lane output. Lanes that relied on `--no-plan` or `bounded` need no flag now; pass `--plan` where planning is wanted.

## Breaking changes

- Replace `--no-plan` and `bounded` with `--plan` or `plan=true` when planning is needed; implementation writers now run directly by default. See [implementation planning](../specs/fabric.md#implementation-planning). (#3370)

## Behaviour changes

- Stale-state, optional-evidence and preference checks gain `policy.<CODE>` rules that default to warn and can be set to `refuse` for strict mode; each warning names the setting source. The rules are listed under `policy_rules` in `config/harness-knobs.json`. Call sites move over in follow-up changes. #3371
- `land` prints the candidate ref, checks URL and state while it waits on a gate, then elapsed time every `land.progress_seconds` (default 60). A candidate whose tree already passed the required checks on a member head skips the gate and records the reused head in the receipt; set `land.reuse_tested_tree = false` to always gate. Each land removes pending records and `land/*` refs of merged or closed pull requests. (#3376)
- Bundled review floors are repository-neutral and warn by default. Projects can declare hard floors for their own boundaries. Verification and synthesis continue after unavailable lenses settle, retaining partial coverage. [#3370](https://github.com/mblauberg/provenant/issues/3370)

## Fixes

- `land --json` keeps `data.steps` as an empty array when publication is refused before local follow-up. (#3376)
- Refused provider continuations now name the rule and affected identity or session-state field in the settled reason, so steering failures can be diagnosed without provider output. (#3379)
- Repair panels now synthesise fresh review findings without requiring dispositions for unrelated earlier findings. [#3370](https://github.com/mblauberg/provenant/issues/3370)
- `retry` of a writer lane that declared a stop resumes from its saved checkpoint, instead of reporting corrupt stored state and leaving the node pending. An interrupted retry resumes its saved generation. (#3382)
- An unclassified provider error keeps its bounded provider message in the reason, alongside the diagnostic. Credential assignments such as `password=…`, `token:…`, `api_key=…` and `Authorization: Basic …` are redacted before the message reaches status or output. (#3375)
- Quoted credential values in lane output stay masked until a quote that every plausible escape layer agrees closes the value, or else through the end of the line. JSON-encoded and nested-escaped credentials no longer leak, and leading whitespace and backslashes inside the value are masked too. (#3381)
