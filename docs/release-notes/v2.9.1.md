# Provenant v2.9.1

Released 24 November 2026.

Provenant 2.9.1 fixes a 2.9.0 regression that refused fresh `--branch` writer launches in a repository holding a stray remote-tracking ref, and stops a checkout with no remote from ever passing an empty remote name to Git.

## Fixes

- A stray remote-tracking ref, such as an old `refs/remotes/review/N` fetch, no longer counts as a Git remote. Before, a repository with one configured remote and such a ref refused every fresh `--branch` writer launch with "no Git remote is declared and none can be inferred". Remotes are the configured ones; tracking-ref directories name remotes only in a store with none configured. (#3874)
- A checkout with no Git remote carries the remote as absent through writer preparation, delivery and hand-off instead of an empty name, so Git never receives `branch.<name>.remote` set to "" or a `refs/remotes//` path; hand-off `--wip` and `recreate` refuse explicitly. (#3869)
