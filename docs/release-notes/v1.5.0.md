# Provenant v1.5.0

Released 3 November 2026.

This release hardens lane recovery and settlement, refuses enclosing credential roots at lane entry, and moves reviews to a shared final-line verdict grammar. It also adds second agy accounts and lane memory sampling on macOS, and migrates the run store to schema 7, which cannot be downgraded.

Provenant makes no stability promise; see [stability](../release-notes/README.md#stability).

## Behaviour changes

- A running lane whose guardian observes provider silence is shown in lane status and wakes lane waits with a distinct non-success result. Silence remains an observation and does not stop the provider (#2374).
- Lane admission and detached workers respect the per-user process limit. A lane waits, reporting `host capacity: user process count N of LIMIT`, when fewer than a tenth of the limit (at least 64) remain, and a detached worker refuses to start. Before, a host near the limit failed later with misleading errors such as "provider protocol is malformed" (#2396).
- Run-store schema 7 adds terminal decision evidence and independent settlement receipts. The migration creates a timestamped SQLite copy before upgrading; downgrade is unsupported, so restoring an earlier version requires that copy or a forward repair (#2463).
- Lane entry refuses a `--read-root` or `--write-root` that encloses a credential root such as `~/.config`, an unsupported write root, or a credential-store write root, naming the flag and path. Entry and the confinement compiler now share one rule, so a root is refused when submitted instead of at compile or child launch; refused child roots settle as refusals. The rule uses the host's canonical home, so a nonconventional home such as `/srv/team/alice` is covered, and read and exec roots inside a Codex standalone release are granted as the compiler grants them (#2380, #2440, #2443).
- `provenant quota` and its menu-bar and console views show when a refused pool resets, so owners can see when it becomes available again (#2536).
- Reviews use the shared final-line [verdict grammar](../specs/fabric.md#typed-node-outputs), and duplicate declarations are treated as unknown. Legacy first-line review outputs stay readable for one release when they contain exactly one declaration (#2371).
- Verdict gates and graph run summaries use canonical review tokens, so review JSON can report `approve_with_nits`. Existing preset and role aliases and stored checkpoint verdict strings are unchanged, and `provenant review` still succeeds only when every reviewer succeeds and approves (#2371).
- Workflow review coverage treats `inconclusive` as non-passing and non-blocking and asks for a fresh review (#2371).
- Blocked launch refusals make `fabric graph run` exit non-zero with the reason. Graph launch failures keep their attempt identity and custody through retry exhaustion or refusal; transient failures, including an unobserved writer disk check, retry with backoff, and a disk-floor refusal remains permanent. Blocked-node remedies now give the supported recovery: fix the cause, cancel the graph, then rerun the document under a new `graph_id` (#2403).
- Review shapes govern lens lists only, so large `big-batch` lane lists expand in full. Omitted lenses are recorded and warned about (#2474).
- Provider updates no longer wait for running lanes to finish. Dispatch waits for a busy provider only up to `--wait`, capped at 30 seconds, then proceeds with the installed version (#2395).

## Additions

- `provenant upgrade` installs the bundled `Provenant Console.app` into `~/Applications` on each host, points an existing menu-bar LaunchAgent at it and restarts the agent. Release packages now include the app. The refresh runs through the packaged installer, keeps the previous app until the menu-bar restart succeeds, and restores it if the refresh fails (#2363, #2417).
- Confined macOS lanes can read their own command tree's resident memory with `provenant process-tree --root PID --json`, which also reports system swap used and total in bytes (null when swap cannot be measured). Unavailable or stale observations exit 4. Stock `ps` still fails inside a lane, so memory guards that invoke it remain blocked (#2452, #2457).
- Writer lanes on macOS can run `swift build` and `swift test` in their worktree. Lanes resolve the host's Swift toolchain, grant it read and execute access only, and put a `swift` wrapper first on `PATH` that keeps SwiftPM caches in the lane cache and names the writable roots when a build fails (#2565).
- A second agy Google account can be registered with its own keychain: give it a home directory holding `Library/Keychains/login.keychain-db` and run `accounts register --adapter agy --directory <home>`. Lanes link only that keychain and `quota` probes it as its own row. Registered agy accounts are pinned and verified at launch, while with no registration agy keeps using the login keychain; a directory other than your home with no keychain file is refused rather than falling back to it. Owner steps are in the [providers runbook](../runbooks/providers.md#agy-accounts) (#2510).
- A read-only `scope` preset refuses tree-write overrides at expansion. Scratch-only runtime confinement is incomplete, because read-only attempts still receive provider and tool grants (#2370).
- Published JSON Schemas in `docs/reference/schemas/` cover the `lanes`, `cancel`, `output` and `status` `--json` envelopes and the MCP tool results. The `lanes`, `cancel` and `output` schemas accept the version 1 envelopes the CLI emits today; the `status` and MCP schemas describe planned typed output, and version 2 is not emitted yet. `scripts/generate-reference --check` detects generated reference drift (#2353).

## Fixes

### CLI and install

- `provenant config migrate` removes the retired `domains.fabric.limits.bundle_bytes` setting, which no longer affects Git transport, and writes that meet the setting now say that `config migrate` removes it (#2377).
- `provenant check release` suppresses only reviewed path, rule and exact-line digest matches, reports changed literals and stale fixture entries, and records the suppression count (#2378).
- `output`, `resume`, `cancel` and `receipt` stop reading the run history as soon as a prefix matches two distinct targets, instead of paging through every lane. Ambiguity reports use the same wording over a bounded list of matches, and multiple attempts of one run count once (#2409, #2434).
- Read-only views of a run (status, lane listings and output paging) no longer force an `F_FULLFSYNC` on every sealed read, so `provenant status` stops spending about 35 seconds in `fcntl` on macOS. Mutating and recovery reads still sync (#2409).
- Installing or upgrading always boots the host tick LaunchAgent out and back in, so launchd no longer kills `dev.provenant.tick` with a Launch Constraint Violation after `~/.local/bin/provenant` is replaced (#2469).
- `run --explain` with `--model` or `--route` shows the route preview without submitting a lane (#2559).

### Lanes and settlement

- Submitting a writer whose `--worktree` belongs to another project now refuses with `WRITER_PROJECT_MISMATCH` and names both project roots, instead of the generic `WRITER_SCOPE` refusal that suggested a write-scope problem (#2366).
- Explicit reconciliation schedules recovery for terminal attempts with retained temporary data or writer reservations, and one damaged attempt no longer hides healthy attempts' results or blocks their recovery. Child lanes can read bundled skills inside an installed release; staging directories and other state roots stay excluded (#2383).
- A legacy slot-root writer reservation fences only the attempt it names, so a successor in the same slot is no longer reported as holding the previous attempt's reservation and its temporary files can be collected. Writer admission still refuses any retained legacy slot-root record, and a record that cannot be read, decoded or validated still counts as retained (#2383, #2433).
- Artifact digest and length refusals name the failed comparison, the artifact, and the expected and actual length or 12-digit digest prefix. A stuck settlement import reports which check refused it, and a streamed result that changes length during its final check names the recorded and observed lengths. No check is looser and no error code changed (#2388).
- Reconciliation accepts older runs whose intact request records predate newer request fields, and still rejects altered records (#2388).
- Recovery no longer retries while a recorded supervisor or guardian is stuck in uninterruptible sleep, and lane status reports the host stall (#2396).
- A supervisor no longer retries exit publication forever when its attempt directory has been removed, including when the sync reports a durability failure. It skips terminal settlement for a provably removed attempt, finishes process cleanup and exits (#2396).
- Writer lanes are no longer rejected with "utility operation has an invalid or unsupported value" when several writers launch at once. The upstream config write now reports the actual `git config` failure (exit status and bounded stderr) and retries only lock contention, within the writer's Git budget and honouring cancellation, so a contended write no longer takes about 25 seconds instead of 5 (#2408).
- Starting and queued lanes surface a failed host resource probe instead of a generic capacity or launch reason. The reason names the failed memory pressure or process budget probe, and says admission continues because the failure is not holding the lane. A full process budget is still reported by count when the memory pressure probe fails (#2425, #2401).
- macOS lanes launched with `--capability postgres` can initialise, query and cleanly stop PostgreSQL. Configure `dynamic_shared_memory_type=mmap` during initialisation and server startup; ordinary lanes keep database IPC denied, and signals outside the lane's sandbox remain denied (#2450).
- macOS lanes deny host process enumeration and argument sysctls while allowing queries about their own processes. Native database checks reclaim their own recorded SysV allocations after failed starts, reducing host IPC exhaustion during verification (#2450, #2451).

### Git and safety

- `provenant land` skips branch deletion when a registered worktree was kept and reports the worktree refusal once. Incomplete worker census refusals identify the process custody could not place and its observation issue, or report an incomplete process listing (#2354).
- Worktree removal refusals for ignored output now name the `gc.projects.<id>.regenerable` setting and how to find the project ID (#2365).
- Worktree removal keeps a tree when a live process's working directory cannot be read on macOS, and treats the process as gone only once an absence probe proves it (#2435).

### Accounts, quota and routing

- `provenant quota` names an exhausted agy pool on the account line, for example `claude pool exhausted (shared)`, and the summary reports a partly spent agy account instead of hiding the shared pool. Routing refuses only the spent pool's models, so an agy gemini lane stays available while the shared Claude pool is out. An uncatalogued agy model such as `agy/gemini-9-pro` now draws on the pool its family names instead of every window (#2369).
- Reading the latest quota figure no longer slows on long unterminated lines in the quota history (#2376).

### Pipelines and graphs

- A tick reports an unreadable graph checkpoint once per record, `graph status` identifies it and `graph cancel` retires it (#2381).
- Nested role indices resolve per child copy, injected read roots are optional for children, required typed parameters name missing values, and node titles use concrete IDs unless overridden. Preset inspection now uses a human table and sections (#2465).

### Chair, inbox and console

- `provenant console open` shows the console window instead of only activating the menu-bar agent, because `Provenant Console.app` now nests the agent as `Provenant Menu.app` (`dev.provenant.menu`, no Dock icon). `provenant upgrade` migrates the existing menu-bar LaunchAgent to the nested helper and restores the previous app and agent if the restart fails (#2473).
- `provenant console open` opens the app by bundle identifier and reports a repair hint when no console process is running, instead of printing "Opened" (#2473).

### Fabric and MCP

- An expired `fabric_run` wait now replies with the same typed wait shape as every other wait, including `attempts: []` and `timed_out: true` when the budget runs out before the first observation, so clients that decode `RunResult` accept it. A timeout outside an exhausted wait budget, or on a non-wait operation, still reports an error (#2302).
- `provenant hosts` reports the base protocol fence beside the local release's newest feature level, for example `protocol=6 features=10`, and shows `features` only on the local row instead of for probed remote peers. A protocol mismatch names the protocol this host expected only when the refusing frame carries it (#2368).

### Telemetry and providers

- Read-only OpenCode lanes can use the built-in grep, glob and list tools again. Shell commands and edits stay denied (#2400).
- Recovery resolves an OpenCode session's model from `<home>/.local/share/opencode` when `XDG_DATA_HOME` is unset, instead of reporting no model (#2416).
