# Provenant v1.5.3

Released 3 November 2026.

This patch release makes review-council lenses emit the findings block the graph requires, so councils complete again. It also stops `provenant land` from keeping worktrees because of a short-lived process outside the repository, makes graph nodes receive upstream results from other Fabric hosts, and lets a preset wait ride out transient scratch-lock errors. Review synthesis completes when the verifier's findings block is broken, and crucial reviews can attach optional mutation evidence.

## Additions

- At crucial or terminal risk, the review council's `tests` lens may attach diff-scoped `cargo mutants` evidence. It is optional and never gates delivery; lower tiers and other lenses are unchanged (#2691).

## Fixes

- Review-council lenses, including the `tests` lens, now end with a schema 1 findings block before their verdict, kept under 32 entries and 8 KiB, with an empty array when there are no findings. Every lens previously failed with "the findings block is missing or invalid" (#2695).
- The worker census retries a process whose descriptor table is briefly unreadable or changing, with a short backoff, so a starting or exiting process outside the repository no longer makes `provenant land` keep its worktree (#2687).
- A graph node now receives an upstream's full redacted result as an input file when that upstream ran on another Fabric host. An unreachable peer still leaves a named notice, and the node runs (#2665).
- `provenant run --preset … --wait` prepares scratch once per wait. Once the graph is admitted, a scratch lock timeout is retried until the wait budget runs out, and the error names the graph (#2512).
- Settlement cleanup takes the writer lock and keeps temporary data for reconciliation when another holder owns it. A stale Git import receipt is superseded once the import resolves (#2546).
- Review synthesis completes when the verifier's findings block is empty or truncated, working from the verifier's prose; each lens prints exactly one verdict line (#2509).
- When the build script cannot resolve the source inventory, its error names the workspace, git's exit status and git's stderr (#2483).
- `provenant check release` matches `release.home-path` only where a path starts, so fixture paths containing `/home/` no longer trip it.
- Test-only fixes: fixture guardians end with their test, lane fixture socket roots keep the short `TMPDIR` alias, test fixtures can cap host lane startup spacing, and the owner-lock retry bound has a test (#2679, #2661, #2653, #2692).
