# Provenant v2.0.3

Released 15 November 2026.

Provenant 2.0.3 adds durable session steering and makes lane recovery easier to inspect. It also fixes linked-worktree writers, review selection and settlement, and chair hooks.

## Behaviour changes

- Review settlement accepts one recognised standalone verdict after a valid handoff, records that tolerance, and gives field-specific errors for malformed findings. Other trailing content remains malformed. (#3313)
- Pinned `provenant run review` ranges now apply configured path floors and size before `@review-panel` expands. (#3324)
- `steer` queues messages durably, interrupts once the live session is known, and continues that session after settlement. Status reports queued, resumed or not-continued delivery without exposing the message; conflicting identity or another stop preserves the message without starting a fresh session. (#3318)

## Fixes

- When `PROVENANT_PROCESS_TREE` is set, `provenant process-tree --json` returns the supervised command's sampled subtree without requiring `--root`. Pass `--root PID` to select a subtree from that sample, as described in the [consumer contract](../specs/consumer-contract.md#process-tree). (#3319)
- `output GRAPH` selects a unique top-level composite, exposes its typed outputs without a synthetic attempt identity, and lists valid choices when ambiguous. Status reports review verdict and findings separately from execution settlement. (#3322)
- `provenant run --branch` now creates managed writers under the primary checkout when launched from a linked worktree or subdirectory, and reports a useful repair when a requested path does not match the configured layout. (#3317)
- A node rerouted after a quota stop inside a composite can now continue from its saved checkpoint. (#3312)
- A patch elsewhere in a graph no longer changes a conditionally skipped composite's state; active composite state is refreshed with the member patch. (#3323)
- `Chair and session hooks` stay quiet in lanes, so lane workers are not prompted to save or restore the chair's checkpoint. (#3314)
- `status --mine` now matches custody to the active harness actor and its saved session when one exists. (#3321)
