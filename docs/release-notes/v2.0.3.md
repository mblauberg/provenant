# Provenant v2.0.3

Released 16 November 2026.

Provenant 2.0.3 adds durable session steering and makes lane recovery easier to inspect. It also fixes linked-worktree writers, review selection and settlement, and chair hooks.

## Behaviour changes

- Review settlement accepts one recognised standalone verdict after a valid handoff, records that tolerance, and gives field-specific errors for malformed findings. Other text around a trailing verdict remains malformed. (#3313)
- Pinned `provenant run review` ranges apply configured path floors and size before `@review-panel` expands. Incomplete metadata uses the configured unreadable-path floors and warns reviewers. (#3324)
- `provenant run review-panel --brief-file ...` carries its brief and pinned range through framing, lenses, verification and synthesis. Review instructions consistently place the verdict before the final handoff. (#3325)
- `steer` queues messages durably for locally launched graph lanes, interrupts once the live session is known, and continues that session after settlement. Status reports queued, resumed or not-continued delivery without exposing the message; conflicting identity or another stop preserves the message without starting a fresh session. A live session mismatch promptly stops the supervised provider. A launched child remains queued until its own stream acknowledges the expected session on the retained route. Live acknowledgement reports resumed promptly; conflicting or incomplete terminal proof changes that status to not continued while retaining the earlier acknowledgement privately. The supervisor seals identity evidence independently of retained output. A truncated final JSON fragment after a confirmed cancel or steer preserves that stop; conflicting identity or lost complete records still prevent continuation. (#3318)

## Fixes

- When `PROVENANT_PROCESS_TREE` is set, `provenant process-tree --json` returns the supervised command's sampled subtree without requiring `--root`. Pass `--root PID` to select a subtree from that sample, as described in the [consumer contract](../specs/consumer-contract.md#process-tree). (#3319)
- `output GRAPH` selects a unique top-level composite, exposes typed-only exports without a synthetic attempt identity, and lists valid choices when ambiguous. Byte pagination preserves multibyte text without panics or stalled offsets. Status reports review verdict and findings separately from execution settlement. (#3322)
- `provenant run --branch` now creates managed writers under the primary checkout when launched from a linked worktree or subdirectory, and reports a useful repair when a requested path does not match the configured layout. (#3317)
- A node rerouted after a quota stop inside a composite can continue from its saved checkpoint. Recovery refreshes active composites and preserves conditional and explicit patch skips until retry supersedes them. (#3312)
- `Chair and session hooks` stay quiet in lanes, so lane workers are not prompted to save or restore the chair's checkpoint. (#3314)
- `status --mine` now matches custody to the active harness actor and its saved session when one exists. (#3321)
