# Provenant v1.2.1

Released 28 October 2026.

This patch release fixes three problems found while upgrading hosts to 1.2.0.

Provenant makes no stability promise; see [stability](README.md#stability).

## Fixes

- `provenant install` restarts the peer LaunchAgent after an upgrade. Previously the agent could be left unable to start (exit status 78) because launchd kept the code requirement of the old binary. When a restart does not produce a new running process, `install` now boots the agent out and bootstraps it again (#1926).
- `cancel` and `reconcile` settle a writer attempt whose `reservation.json` has gone, when its custody checkpoint records guardian and provider identities from an earlier boot. The attempt ends as lost, with the cause, instead of staying `running`. An attempt from the current boot, or one without those identities, stays uncertain (#1928).
- `lanes` shows `disk guard paused builds (free X GiB, resumes at Y GiB)` for running lanes while the disk guard holds builds stopped (#1930).
