# Provenant v1.4.1

Released 30 October 2026.

Provenant makes no stability promise; see [stability](../release-notes/README.md#stability).

## Additions

- The Console inbox is a native three-column window with smart filters, per-project counts, a dense request list and a Markdown detail pane. Rows show the request kind, project, session, relative age and a blocking marker; the detail pane marks the recommended option and keeps delivery and stale-revision results inline.
- The Console is keyboard first: j and k move, 1 to 9 choose an option, Return sends, ⌘F searches, ⌘1 to ⌘5 choose filters and ⌘R refreshes. It also has a real empty state, an error state that keeps the last list, a restored window frame and VoiceOver labels on every control.

## Fixes

- `provenant config migrate` (with `--dry-run` and `--json`) rewrites the retired `starts_unix_seconds`, `expires_unix_seconds` and `windows` routing keys to `schedule` after saving a timestamped backup, and drops pacing overrides that have expired. The load warning and the refusal of config writes such as `provenant accounts register` now name it as the repair.
- An agy quota probe that finds a different Google account signed in than the registered one reports `account_mismatch` and the `provenant accounts register --adapter agy --directory <dir> <label>` repair, instead of looking like a sign-out. The account stays `auth_required` for dispatch until it is re-registered.
- `provenant run --mode read-only --worktree` is refused as a mismatched mode instead of being turned into a writer run, which made read-only models such as `agy/gemini-3.8-flash` fail with `model policy restricts this route to read-only and review work`.
- The Console lists the open requests of every registered project on the host, each row naming its project, and answers them. It uses the new `--all-projects` mode for listing, inspecting and answering requests, regardless of its working directory. Host-wide lists support cursors and filters; without the flag, inbox commands remain scoped to the current project and report `no_project` with a repair when no project resolves.
- `Provenant Console.app` now has the Provenant icon, compiled from `assets/brand/Provenant.icon` by `bundle` when Xcode is installed.
