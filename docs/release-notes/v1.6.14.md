# Provenant v1.6.14

Released 7 November 2026.

Version 1.6.13 could fail several writer launches started at the same moment with a writer-lock error; 1.6.14 makes them wait instead, within the launch wait budget. This release also adds graph tracing and fixes credential masking and launch validation.

## Additions

- `trace GRAPH` shows the recorded graph timeline and attempt measurements, including cache share.

## Fixes

- Garbage collection removes old abandoned ingest and install staging files, and review of a merge commit uses its first parent.
- Writers that stop without a new commit now say they stopped with no work and acceptance remains unmet. Graph writer nodes continue once automatically in the same worktree; set `auto_continue_no_work = false` to disable this. Stopping a settled writer also prevents its pending automatic continuation.
- Stored lane output now masks recognised credentials containing JSON Unicode escapes.
- Concurrent writer launches on distinct branches now wait for the repository registry within the launch wait budget. A lock held beyond that budget fails with `writer_lock_busy`, and launch failures before an attempt exists include the code and message in the JSON error.
- Writer launches retry transient directory holders within their remaining wait budget. An inconclusive retry keeps the holder refusal; worktree removal refuses holders immediately (#3015).
- Child launches reject document controls they cannot apply, naming the field. Authored graph documents reject unsupported or non-integer schema versions (#3015).
- Templates reject undeclared node fields, including overrides and composite members. Review flavours preserve their lens when adding metadata, and authorised repair continuations compile successfully (#2878).
- Graph launches distinguish failures before an attempt from failures after one, and concurrent writer launches tolerate transient checkout inspection handles.
