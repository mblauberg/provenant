# Provenant v1.6.7

Released 6 November 2026.

This release lets routing use accounts with stale availability and repairs graph runs that died on their own records. There are no breaking changes.

## Additions

- Attach images to lanes with `run --attach` or graph node `attachments` (#2515).
- Model-choice suggestions can be accepted as expiring routing preferences for a risk tier and task kind (#2011).
- `deliver --plan on` plans its review panel against the pinned writer head, retaining configured review floors (#2836).
- Graph document size refusals name the limit and the graph reader that owns it.

## Fixes

- A process outside candidate worktrees with unreadable descriptors no longer makes every writer's occupancy unknown.
- Writer lanes can launch on packed branches even when the loose ref directory is absent.
- Graphs can resume after a read-only route fallback and accept longer expanded node IDs. Joins wait for sibling work to settle before reporting failures.
- Routing can use an identified account with stale or unknown availability, with a lane warning, and reports each account when all are excluded (#2952).
- Claude quota probes distinguish malformed responses and expired credentials from network failures (#2952).
- JSON graph previews include the advisory warning when the writer tier mix is inverted (#2720).
- Preset compilation and graph admission enforce the configured composite nesting depth before launch (#2878).
- Invalid loop round settings fail during preset compilation, and loop safety refusals name their bound and owner (#2878).
- Preset compilation counts expanded composite and loop nodes the same way as graph admission (#2878).
- Preset compilation names malformed graph and node settings in its errors (#2878).
- Preset leaf stages accept graph node fields and report unknown fields with the stage name (#2878).
- Experiment arms receive declared request bindings, and parameter files override selected and request values consistently (#2878).
- Remote submissions check peer compatibility before launch and name the upgrade command when the peer is too old (#2351).
- Remote submissions can recover their receipt when a peer health check fails or omits capability details (#2351).
- Chair turns now ingest recent native usage when they finish and resume from the last complete transcript line. Native attempts can be tracked by alias and linked to their usage (#2718).
