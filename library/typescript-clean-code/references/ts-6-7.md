# TypeScript 6 and 7

Checked: 30 October 2026. Check the installed compiler and tooling peers against the [release announcements](https://devblogs.microsoft.com/typescript/) and [release notes](https://www.typescriptlang.org/docs/). TypeScript 6 changes configuration defaults and deprecates older options; TypeScript 7 uses a native compiler. Tools using the JavaScript compiler API may require a separate compatible compiler. Inspect the project's actual configuration and diagnostics before migrating.
