# Lens: conventions and readability

Shared guidance: [review-lenses.md](../review-lenses.md).

- Compare naming, layout, error style and test style with the neighbouring code
  and the project instructions.
- Comments should explain why, and describe live behaviour rather than history.
- Public behaviour changes need their docs, help text and release notes updated.
- Check control flow a new maintainer could not follow without the author.
