# Reproduction evidence

Record the command, environment, inputs and observed symptom in a run-owned artefact. Repeat the signal and distinguish setup failures from the reported defect. Use a focused test, CLI fixture, HTTP replay, property loop or git bisect according to the seam.

For flakes, record the sample size and reproduction rate. For stochastic searches, report the best result found within the sampled envelope, not impossibility. Preserve the evidence and remove only run-owned instrumentation.
